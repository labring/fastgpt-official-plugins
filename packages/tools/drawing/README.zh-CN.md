# BI 图表生成 (BI Charts)

BI 图表生成插件是 FastGPT 官方提供的轻量化数据可视化工具集（Tool Set）。该插件内置基于 ECharts 的服务端无头渲染（SSR）引擎，支持将离散的数据指标快速转换为精美的**折线图**、**柱状图**与**饼图**，并自动上传至 FastGPT 存储生成可直接在聊天界面中展示的图片直链。

## 应用场景

- **智能数据看板与统计汇总**：结合数据库查询或 API 结果，将枯燥的数字转换为直观的可视化图表。
- **对话内数据直观呈现**：大模型分析报表或对比数据后，自动调用图表工具绘制趋势图或占比图，提升交互体验。
- **业务周报与分析报告自动配图**：在工作流中自动生成带图表的结构化业务汇报，一键推送到企业微信、飞书或邮件。
- **问卷调研与统计占比可视化**：将各选项投票数或比例实时渲染为饼图或柱状图呈现。

---

## 子工具列表

| 子工具 ID | 名称 | 说明 |
| :--- | :--- | :--- |
| `baseChart` | 基础图表 (baseChart) | 根据输入的 X 轴、Y 轴与类型配置，渲染生成折线图、柱状图或饼图 |

---

## 输入参数说明 (`baseChart`)

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `title` | 字符串 | 否 | `""` | 图表标题，展示在图表顶部居中位置。 |
| `xAxis` | 字符串数组 / JSON 字符串 | **是** | - | X 轴分类维度或标签数据。例如：`["1月", "2月", "3月"]`。若输入字符串，需符合 JSON/JSON5 数组格式。在饼图中作为各扇区的分类名称。 |
| `yAxis` | 字符串/数值数组 / JSON 字符串 | **是** | - | Y 轴指标数值数据。例如：`["120", "200", "150"]`。在折线图与柱状图中作为数值刻度，在饼图中作为扇区数值。 |
| `chartType` | 单选枚举 | **是** | - | 图表类型，可选值：`折线图`、`柱状图`、`饼图`。 |

---

## 输出结果说明 (`baseChart`)

| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `chartUrl` | 字符串 | 生成的图表图片持久化直链。在聊天框或 Markdown 节点中可直接使用 `![图表](chartUrl)` 语法渲染展示。 |
| `图表 url` | 字符串 | 兼容旧版输出字段，值与 `chartUrl` 相同。 |

### 输出示例

```json
{
  "chartUrl": "https://fastgpt.run/api/system/upload/chart-20250520-abc123.svg"
}
```

### 提示词引导建议 (System Prompt)

当引导大模型调用 `baseChart` 工具时，建议在提示词中规范其入参提取格式：

```text
当用户要求将数据以图表形式展示时，请提取出分类项作为 xAxis 数组，数值项作为 yAxis 数组，并根据数据特征选择最合适的 chartType（时间趋势推荐使用“折线图”，对比数据推荐使用“柱状图”，占比结构推荐使用“饼图”）。
```

## 注意事项

1. **数组长度对齐**：`xAxis` 与 `yAxis` 的数组长度必须一致，否则可能导致图表渲染不全或错位。
2. **数值解析**：`yAxis` 中的字符串项会被自动转换为浮点数值，非数字字符可能解析为 `NaN`。
3. **渲染尺寸与格式**：图表默认以 400x300 分辨率渲染为矢量 SVG 图像，清晰且体积小巧。
