# DuckDuckGo 搜索工具集

DuckDuckGo 服务是一款面向 FastGPT 的多功能隐私搜索工具集（Tool Suite）。该工具集集成了 DuckDuckGo 强大的网页、图片、新闻及视频检索能力，为智能体与工作流提供实时、全面的外部信息获取通道。

## 核心优势与应用场景

### 核心优势
- **免 API Key 与零配置**：完全无需注册第三方账号或配置繁琐的 API 密钥，开箱即用。
- **隐私保护与无追踪**：DuckDuckGo 不追踪用户搜索行为与个人身份，保障企业和个人的搜索数据隐私。
- **全方位搜索覆盖**：集成网页、图片、新闻、视频 4 种子工具，满足多样化多模态检索需求。
- **内置容错与退避机制**：各子工具内置最多 3 次自动重试及随机退避（0~5 秒延时），有效应对瞬时网络波动。
- **默认严格安全过滤**：全量开启严格模式（SafeSearch STRICT），过滤成人与违规内容，输出安全可靠。

### 应用场景
- **AI 联网搜索增强 (RAG)**：在问答或写作时动态获取最新的公开网络信息、事实依据与参考资料。
- **实时资讯追踪**：利用新闻检索子工具快速搜集行业突发事件、政策动向与科技趋势。
- **多模态素材推荐**：为智能体赋予配图和视频检索能力，根据上下文自动推荐高清图片或相关视频。
- **轻量低成本搜索**：无需为高昂的商业搜索引擎 API 付费，适合开发测试与中低频生产环境。

## 参数与输出说明

### 1. 网页检索 (`search`)

使用 DuckDuckGo 检索全网网页信息，默认检索近一年内最相关的 10 条网页结果。

#### 输入参数

| 参数名 | 类型 | 必填 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| `query` | string | 是 | - | 要检索的关键词。 |

#### 输出结果

| 参数名 | 类型 | 描述 |
| :--- | :--- | :--- |
| `result` | string | 网页搜索返回的结果，为 JSON 格式的字符串列表。 |

**输出示例 (`result` 解析后)：**
```json
[
  {
    "title": "FastGPT - 基于 LLM 的知识库问答系统",
    "link": "https://fastgpt.in",
    "snippet": "FastGPT 是一个基于 LLM 大语言模型的知识库问答系统，提供开箱即用的大模型数据处理、工作流编排等能力..."
  }
]
```

## 使用示例与工作流集成

### 在 FastGPT 工具节点中使用
在 FastGPT 的“高级编排”中添加工具节点，选择对应的 DuckDuckGo 子工具（如 `DuckDuckGo 网络搜索`）：

1. **输入配置**：将大模型提炼的搜索关键词（如 `"FastGPT 插件开发规范"`）绑定至 `query`。
2. **作为 LLM 上下文**：工具执行后，`result` 字段将输出 JSON 格式的搜索数据，可直接连接至后续的大模型节点，提示词例如：
   ```text
   请根据以下从 DuckDuckGo 搜索到的网页参考内容回答用户的问题：
   {{search.result}}
   ```
3. **结构化解析（可选）**：如需提取单一图片链接展示给用户或发送卡片，可通过“代码运行”节点运行 `JSON.parse(result)` 提取特定属性（如 `image` 或 `url`）。

## 注意事项

1. **网络连接与连通性依赖**：
   - DuckDuckGo 在某些国家与地区（如中国大陆）可能无法直接访问。请确保运行 FastGPT 服务或插件宿主容器的网络环境具有良好的外网连通性。
2. **免 Key 与请求频率限制 (Rate Limit)**：
   - 本工具集基于 DuckDuckGo 公开网页接口实现，无需申请任何 API Key；但频繁并发请求可能触发上游防爬或速率限制（HTTP 429 / 403）。建议在生产环境中避免过于密集的高并发调用。
3. **容错机制与自动重试**：
   - 内部已封装 3 次错误自动重试逻辑，且每次重试前会进行 0~5 秒随机延时退避。若全部重试均失败，将在 `result` 中返回错误描述文本，不会中断整个工作流实例。
4. **安全搜索策略 (SafeSearch)**：
   - 所有子工具均默认启用 `SafeSearchType.STRICT`（严格安全搜索），有助于过滤不良内容，适合构建严谨的企业级智能体应用。
5. **返回内容长度控制**：
   - 各工具每次请求最多截取前 10 条结果返回，以平衡信息丰富度与 LLM Context Token 消耗。
