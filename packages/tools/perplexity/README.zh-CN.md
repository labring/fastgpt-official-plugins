# Perplexity 智能搜索与问答工具集 (Perplexity Tool Set)

Perplexity 是业内领先的对话式 AI 搜索引擎与信息检索服务。本工具集为 FastGPT 智能体与工作流提供实时互联网检索与精准摘要能力。借助 Perplexity 强大的搜索能力，可快速获取高时效性信息、权威网页来源以及带有上下文引用的事实依据，显著提升大模型的回答准确度并有效抑制模型幻觉。

---

## 典型应用场景

- **实时联网问答前置检索**：在智能体回答涉及突发事件、最新事实或未知领域的提问时，先行调用 Perplexity 进行实时网页检索，注入最新权威事实。
- **科技时事新闻检索**：快速追踪前沿科技进展、行业热点资讯、开源生态演进及政策动态，获取第一手参考资料。
- **高质量引用信源获取**：自动提取网页来源的标题（Title）、链接（URL）与上下文摘要片段（Snippet），便于下游大语言模型输出带有可核查信源标注的回答。
- **知识库 RAG 增强**：当本地私有知识库置信度不足或未覆盖用户问题时，作为外置网络搜索源进行混合检索与知识补充。

## 密钥配置说明

使用本工具集需要配置 Perplexity API Key（`apiKey`）。

### 获取渠道与申请指引

1. 访问 [Perplexity 开发者平台设置页面](https://www.perplexity.ai/settings/api)。
2. 登录或注册 Perplexity 账号。
3. 进入 **API Settings** 页面，绑定结算支付方式（如需要）。
4. 在 **API Keys** 区域点击 **Generate** 创建新的 API 密钥（通常为 `pplx-...` 格式）。
5. 复制并妥善保管生成的 API 密钥。

### 配置方式

在 FastGPT 插件配置的「全局变量 / 密钥 (Secrets)」区域中填写以下字段：

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `apiKey` | 字符串 (`string`) | 是 | Perplexity API 密钥。将用于调用 Perplexity 官方检索接口进行鉴权认证。 |

| `findResults` | 网络搜索 (`Network Search`) | 全网实时搜索与精准摘要检索。使用 Perplexity 搜索网络，并返回带引用的结构化网页结果。 |

## 参数与输出说明

### 网络搜索 (`findResults`)

通过 Perplexity 全网检索指定内容，返回按相关度排序的网页标题、链接及文本摘要。

#### 输入参数

| 参数名 | 类型 | 必填 | 默认值 | 取值范围 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `query` | 字符串 (`string`) | 是 | 无 | 长度 > 0 | **查询词**。要在网络上搜索的查询关键词或自然语言问题。 |
| `max_results` | 数值 (`number`) | 否 | `10` | `1` ~ `20` | **最大结果数**。最多返回的搜索结果条数。默认为 10，最大支持 20。 |

#### 输出结果

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `result` | 对象数组 (`Array<Object>`) | Perplexity 网络搜索返回的结构化结果列表。 |

**`result` 数组条目结构：**

| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `title` | 字符串 (`string`) | 搜索结果网页标题。 |
| `url` | 字符串 (`string`) | 搜索结果目标网页的完整 URL 访问链接。 |
| `snippet` | 字符串 (`string`) | 搜索结果网页内容的简短上下文摘要片段。 |

#### 输出示例 (`result`)

```json
{
  "result": [
    {
      "title": "FastGPT - 基于 LLM 的知识库问答系统",
      "url": "https://fastgpt.in",
      "snippet": "FastGPT 是一个基于 LLM 大语言模型的知识库问答系统，提供开箱即用的大模型数据处理、工作流编排等能力..."
    },
    {
      "title": "FastGPT 官方文档与插件体系",
      "url": "https://doc.fastgpt.in",
      "snippet": "详细了解 FastGPT 插件机制与工具节点编排，支持接入 Perplexity、Tavily、Google 等多样化搜索与业务工具..."
    }
  ]
}
```

## 典型工作流编排示例

本工具集常用于构建“联网检索增强（Web RAG）”工作流。以下为一个经典编排链路：

```
[用户提问]
   │
   ▼
[大模型节点：意图识别与关键词提取]
   │ (输出提取后的 query)
   ▼
[Perplexity 工具节点：findResults]
   │ (输出检索结果 result)
   ▼
[下游大模型节点：带引用整合回答]
   │
   ▼
[输出最终回答]
```

### 编排步骤

1. **大模型意图提取**：
   - 接收用户输入（例如：“最近 FastGPT 有哪些重要版本更新？”）。
   - 由前置大模型判断是否需要联网，并将问题精炼为高效的搜索关键词传递给下游变量（如 `query: "FastGPT release notes updates"`）。

2. **Perplexity 搜索工具节点**：
   - 添加「Perplexity 工具集」下的「网络搜索 (`findResults`)」节点。
   - 输入参数配置：
     - `query`：连接前置大模型生成的搜索词变量。
     - `max_results`：设置为 `5` ~ `10`，兼顾信息全面性与上下文 Token 消耗。

3. **下游模型带引用回答**：
   - 将 `findResults.result` 作为上下文传入下游大模型节点。
   - 提示词（Prompt）参考模板：

```text
你是一个专业的智能问答助手。请根据以下从 Perplexity 检索到的参考信源，回答用户的问题。

### 参考信源：
{{findResults.result}}

### 回答规范：
1. 严格依据参考信源内容进行归纳和回答，不要编造未提及的事实。
2. 回答需条理清晰、重点突出。
3. 请在陈述关键事实或数据后，使用 Markdown 链接标注信源出处，格式为：[网页标题](URL)。
4. 若参考信源中未包含足够的信息来回答该问题，请客观告知用户。

用户问题：{{input.question}}
```

## 注意事项

1. **API 计费与配额**：
   - 调用 Perplexity API 会按照 Perplexity 官方资费标准消耗账户额度。请确保账户余额充足或绑定有效支付方式。
   - 建议在工作流中合理配置 `max_results`（如设为 5~10），避免过大的 Token 消耗和不必要的开销。
2. **网络连通性要求**：
   - Perplexity API 服务端地址为 `https://api.perplexity.ai`，FastGPT 服务端或插件执行宿主网络需具备外网访问该域名的能力。
   - 如处于受限网络环境，请配置相应的网络代理或出口网关。
3. **参数约束**：
   - `max_results` 的有效范围为 `1` 到 `20`，超出范围会抛出输入校验异常。
4. **密钥安全管理**：
   - API Key 属于重要身份凭据，请仅在 FastGPT 的密钥管理（Secrets）中保存，避免在公开提示词或日志中明文记录。
