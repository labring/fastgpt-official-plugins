# Markdown to Office Document (markdownTransform)

`markdownTransform` (Markdown to File) is an official FastGPT plugin for generating and converting office documents. It transforms standard Markdown text generated by Large Language Models (LLMs) or upstream workflow nodes into high-quality Microsoft Office documents (supporting Word `.docx`, Excel `.xlsx`, and PowerPoint `.pptx`). It automatically uploads and persists files to FastGPT's storage service, returning a direct download link for end users.

---

## Application Scenarios

- **One-Click Word Export (.docx) from LLM Reports**: In scenarios such as long-form writing, industry research reports, official summaries, or Product Requirement Documents (PRDs), export multi-level headings, bulleted lists, code blocks, and tables into professionally formatted Word documents ready for offline editing and archiving.
- **One-Click Excel Export (.xlsx) from Data Tables**: Pair with data analytics agents, SQL generation tools, or financial reporting workflows to map LLM-generated Markdown tables directly into Excel sheets with bold headers, adaptive column widths, and embedded cell images for secondary calculations and data distribution.
- **One-Click PowerPoint Presentation (.pptx) from Presentation Outlines**: Automatically partition slides according to Markdown heading levels. Generate cover title slides, chapter section slides, rich-text body slides, native tables, and full-width image slides to quickly draft presentations and training materials.
- **Archiving Chat Conversations as Enterprise Documents**: In customer service quality assurance, project reviews, or expert consultations, archive multi-turn conversations or workflow summaries directly into enterprise-grade office documents for distribution.

---

## Core Features

- **No External Third-Party API Key Required**: Built on high-performance local Node.js document generation libraries (`docx`, `exceljs`, `pptxgenjs`, and `markdown-it`). Operates with zero third-party cloud conversion dependencies, eliminating API key configuration, extra token costs, or call fee burdens while maintaining data privacy.
- **Native Support for Major Office Formats**:
  - **Word (DOCX)**: Full support for H1–H6 heading mappings to Word native Heading styles, multi-level indentations and numbering for ordered/unordered lists, inline styles (bold, italic, inline code, hyperlinks), full-width tables, and standalone code blocks with background shading and borders.
  - **Excel (XLSX)**: Intelligently detects Markdown table structures, automatically calculates optimal column widths and row heights, formats plain text paragraphs line-by-line, and downloads and embeds network images into worksheet cells.
  - **PowerPoint (PPTX)**: Intelligent slide partitioning based on heading hierarchies and content height, supporting cover title layouts, native PPT table rendering, and dedicated full-size image slides.
- **FastGPT Persistent File Storage & Direct Download Link**: Declared with FastGPT's `file-upload:allow` permission. Once the document is generated, it is automatically uploaded to FastGPT's object storage (S3/MinIO) and returns a secure, persistent download URL. Seamlessly falls back to a Base64 DataURL in local development environments without an upload context.
- **Adaptive Network Image Retrieval & Embedding**: Automatically downloads `![alt](url)` network images across DOCX, XLSX, and PPTX formats, detects image formats (PNG, JPEG, GIF, BMP) and dimensions, and scales them proportionally to fit the document layout.

## Input Parameters

| Parameter | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `markdown` | string | Yes | None | The Markdown text content to convert. Supports standard Markdown syntax including headings, paragraphs, lists, tables, code blocks, and network images. |
| `format` | enum | Yes | None | The target conversion format. Available options:<br>• `docx`: Export as Microsoft Word document (`.docx`)<br>• `xlsx`: Export as Microsoft Excel spreadsheet (`.xlsx`)<br>• `pptx`: Export as Microsoft PowerPoint presentation (`.pptx`) |
| `filename` | string | No | See description | Optional custom filename (**without file extension**). For example, providing `Annual_Report_2024` will generate `Annual_Report_2024.docx` for Word format. If omitted, default filenames are:<br>• `docx` format: `markdown-to-docx`<br>• `xlsx` format: `markdown-to-excel`<br>• `pptx` format: `markdown-to-pptx` |

---

## Output Results

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `url` | string | The direct download URL of the converted document. In FastGPT runtime environments, this is the accessible URL of the persisted file in cloud storage, which can be directly referenced in downstream response nodes for user downloads. In local testing environments without an upload context, a Base64 DataURL is returned. |

### Output Example

```json
{
  "url": "https://api.fastgpt.in/api/v1/system/file/view/66f1234567890abcdef.docx"
}
```

## Typical Workflow Orchestration

### Scenario: LLM Generates Report and Exports Downloadable Office Document

The most common end-to-end workflow pattern in FastGPT is structured as follows:

```
[User Trigger / Query] ──> [AI Chat (LLM Structured Output)] ──> [Markdown to File (markdownTransform)] ──> [Response Node (Download Card)]
```

#### Orchestration Steps:

1. **Configure "AI Chat" Node**:
   - Guide the LLM to output content using standard Markdown syntax, including clear heading levels and valid tables.
   - Example Prompt:
     ```markdown
     Please draft a professional analysis report according to the user's requirements.
     Strictly follow standard Markdown formatting:
     - Use # for the main title and ## for chapter/section headings;
     - Present numerical data comparisons using standard Markdown tables;
     - Highlight key takeaways using bold text.
     ```

2. **Configure "Markdown to File (markdownTransform)" Node**:
   - **`markdown`**: Connect to the output variable of the upstream "AI Chat" node (e.g., `{{llm.answer}}`).
   - **`format`**: Select `docx`, `xlsx`, or `pptx` according to business requirements (or dynamically choose via a preceding classifier).
   - **`filename`**: Specify a static name (e.g., `Business_Analysis_Report`) or bind to a dynamic title variable generated upstream.

3. **Configure "Response" Node**:
   - Receive the `url` output from `markdownTransform` and provide an interactive download card:
     ```markdown
     Your document has been generated successfully! Click the link below to download:

     📄 **[Click Here to Download Document]({{markdownTransform.url}})**

     > 💡 **Tip**: The file is stored in cloud storage with an expiration period. Please download and save it locally as soon as possible.
     ```

## Notes & Syntax Specifications

### 1. Table Mapping Rules for XLSX (Excel)
- **Table Prioritization**: The converter automatically detects Markdown tables (requiring standard delimiter rows like `| --- | --- |`). The first row is parsed as the table header and styled in bold centered text.
- **Adaptive Column Widths**: Automatically computes column widths based on maximum character lengths (auto-adapting between 15 and 30) to prevent text clipping.
- **Plain Paragraph Text**: Non-table paragraphs and lists are sequentially written to column A of the worksheet with text wrapping (`wrapText`) enabled.
- **Cell Images**: Images formatted as `![alt](url)` within table cells are downloaded via HTTP and proportionally scaled and embedded into cells.

### 2. Slide Partitioning Rules for PPTX (PowerPoint)
- **Cover Title Slide**: Sections starting with a level-1 heading (`# Title`) generate a standalone slide featuring centered large title text.
- **Content Slide Partitioning**: Level-2 headings (`## Heading`) initiate a new slide as the chapter/topic heading, with subsequent paragraphs and lists arranged vertically as bullet points.
- **Height Overflow Auto-Split**: When the cumulative vertical height of content on a single slide exceeds the threshold, the engine automatically creates a new slide to host the remaining content.
- **Dedicated Image Slides**: Each network image `![alt](url)` in the content generates a dedicated slide with full-size proportional centering.
- **Native Table Support**: Markdown tables are converted into native PowerPoint table shapes, retaining row and column structures.

### 3. Formatting Rules for DOCX (Word)
- **Heading Mapping**: Markdown `#` to `######` map directly to Word native styles `Heading 1` through `Heading 6`, creating an outline structure for table of contents generation.
- **List Styling**: Supports nested indentation and numbering for both ordered lists (consecutive digits) and unordered bulleted lists (`•`).
- **Code Block Styling**: Fenced code blocks (```) are rendered in monospace font (Courier New) with light-gray background shading and borders.
- **Inline Formatting & Media**: Supports bold, italic, inline code, and hyperlinks alongside embedded network images with proportional dimensions.

### 4. File Expiration & Storage Considerations
- **Storage Permissions**: The plugin utilizes FastGPT's `file-upload:allow` permission to persist generated Office documents to FastGPT's object storage.
- **URL Validity**: The returned download URL may have an expiration period determined by FastGPT's object storage signed URL policy. It is recommended to remind users to save files promptly.
- **Network Image Availability**: Images referenced in Markdown must be publicly accessible via `http://` or `https://`. If an image URL is invalid, blocked by hotlink protection, or times out, a fallback placeholder text is displayed without interrupting the document generation process.
