# Markdown 转 Office 文档 (markdownTransform)

`markdownTransform`（Markdown 转文件）是 FastGPT 官方提供的办公文档生成与转换插件。它能够将大语言模型（LLM）或上游流程生成的标准 Markdown 格式文本，快速转换为高质量的 Microsoft Office 文档格式（支持 Word `.docx`、Excel `.xlsx`、PowerPoint `.pptx`），并通过 FastGPT 文件存储服务自动完成持久化上传，直接返回可供用户点击下载的文件直链。

---

## 典型应用场景

- **大模型生成报告一键导出 Word (.docx)**：在长文写作、行业研报分析、公文总结、产品需求文档 (PRD) 等场景下，将大模型输出的多级标题、要点列表、代码块与表格一键沉淀为排版规范的 Word 文档，方便离线编辑与打印归档。
- **数据分析表格一键导出 Excel (.xlsx)**：配合数据统计 Agent、SQL 生成工具或财务分析流程，将大模型生成的 Markdown 结构化表格自动映射为 Excel 工作表，支持表头加粗、列宽自适应与单元格图片嵌入，方便二次计算与数据流转。
- **演讲大纲一键转换为 PPT 演示文稿 (.pptx)**：依据 Markdown 标题层级自动切分幻灯片分页，支持生成封面大标题页、章节主题页、富文本正文、原生表格与全幅图片幻灯片，助力演讲提纲、培训教案快速生成课件初稿。
- **会话记录沉淀为企业文档**：在客服质检、项目评审、专家咨询等场景中，将多轮人机交互记录或工作流总结信息直接归档导出为办公文档分发。

---

## 核心功能特性

- **免外部第三方 API 密钥**：基于 Node.js 本地高效文档生成引擎（`docx`、`exceljs`、`pptxgenjs`、`markdown-it`）进行解析与渲染，零外部云端转换接口依赖，无需配置任何第三方 API Key，无额外 Token 或调用费用负担，安全可控。
- **原生支持主流 Office 格式**：
  - **Word (DOCX)**：完整支持 H1~H6 标题与 Word 原生 Heading 层级映射、有序与无序列表的多级缩进与序号显示、行内样式（粗体、斜体、行内代码、超链接）、全宽表格与带背景边框的独立代码块。
  - **Excel (XLSX)**：智能提取 Markdown 表格结构，自动计算最适列宽与行高，支持将普通段落文本按行排版，并支持自动下载网络图片嵌入至工作表单元格。
  - **PowerPoint (PPTX)**：基于标题分级与内容高度实现智能切页，支持大标题封面页排版、原生 PPT 表格渲染以及独立全尺寸图片幻灯片生成。
- **FastGPT 文件持久化存储与下载直链**：已声明并获得 FastGPT `file-upload:allow` 权限，生成文件后自动调用 FastGPT 平台文件上传接口存储至对象存储（S3/MinIO），生成安全持久的文件访问直链（URL）；在无上传上下文的本地调试环境可平滑降级为 DataURL。
- **网络图片自适应抓取与嵌入**：在 DOCX、XLSX、PPTX 三种格式中均支持自动识别并下载 `![alt](url)` 格式的网络图片，自动探测图片格式（PNG/JPEG/GIF/BMP）与物理尺寸，按版面自适应等比缩放嵌入文档中。

## 输入参数

| 参数名 | 字段类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `markdown` | 字符串 (`string`) | 是 | 无 | 待转换的 Markdown 格式文本正文。支持标准 Markdown 语法（标题、段落、列表、表格、代码块及网络图片等）。 |
| `format` | 枚举 (`enum`) | 是 | 无 | 目标转换格式。可选值：<br>• `docx`：导出为 Word 文档 (`.docx`)<br>• `xlsx`：导出为 Excel 电子表格 (`.xlsx`)<br>• `pptx`：导出为 PowerPoint 幻灯片 (`.pptx`) |
| `filename` | 字符串 (`string`) | 否 | 见说明 | 自定义导出文件名（**不包含扩展名**）。例如传入 `2024年度经营报告`，转换后将自动根据目标格式生成 `2024年度经营报告.docx`。若不传，默认文件名分别为：<br>• `docx` 格式：`markdown-to-docx`<br>• `xlsx` 格式：`markdown-to-excel`<br>• `pptx` 格式：`markdown-to-pptx` |

## 输出结果

| 字段名 | 字段类型 | 说明 |
| :--- | :--- | :--- |
| `url` | 字符串 (`string`) | 转换后生成的文档下载直链。在 FastGPT 运行环境中为已上传持久化的文件访问地址，可在后续回复节点中直接构造成超链接供用户点击下载。在无上传上下文的本地调试环境下返回 Base64 DataURL。 |

## 典型工作流编排示例

### 场景：大模型生成报告并导出 Office 文档下载

在 FastGPT 中最典型的端到端编排方案如下：

```
[用户提问/指令触发] ──> [AI 对话 (LLM 规范生成)] ──> [Markdown 转文件 (markdownTransform)] ──> [指定回复 (输出下载卡片)]
```

#### 编排步骤：

1. **配置「AI 对话」节点**：
   - 引导大模型按照规范的 Markdown 语法输出正文，如清晰的标题分级、标准表格等。
   - 提示词示例：
     ```markdown
     请你根据用户的要求撰写一份专业的分析报告。
     请严格遵循标准 Markdown 语法排版：
     - 使用 # 作为大标题，## 作为各章节标题；
     - 如有数据对比，请使用标准 Markdown 表格展示；
     - 重点内容使用粗体标注。
     ```

2. **配置「Markdown 转文件 (markdownTransform)」节点**：
   - **`markdown`**：连接至上游「AI 对话」节点的回复内容变量（如 `{{llm.answer}}`）。
   - **`format`**：根据业务需要选择 `docx`、`xlsx` 或 `pptx`（也可以通过前置分类器由用户意图动态决定）。
   - **`filename`**：可指定固定名称（如 `业务分析报告`）或引用上游节点生成的标题变量。

3. **配置「指定回复」节点**：
   - 接收 `markdownTransform` 节点输出的 `url`，组织友好的 Markdown 下载卡片引导用户下载：
     ```markdown
     您的文档已经生成完毕！请点击下方链接直接下载：

     📄 **[点击立即下载文件]({{markdownTransform.url}})**

     > 💡 **提示**：文件已保存至云端，链接具有有效期，请尽快下载保存至本地。
     ```

## 注意事项与语法规范

### 1. 转 XLSX (Excel) 时的表格映射规则
- **表格优先识别**：转换器会自动定位 Markdown 表格块（需具备 `| --- | --- |` 分割行）。表格第一行将被解析为表头，格式设为粗体居中。
- **自适应列宽**：插件会根据每列文本的最大字符长度动态计算列宽（在 15 至 30 之间自动适配），避免内容重叠或被遮挡。
- **非表格普通文本**：Markdown 中的普通段落文本与列表将被顺序写入 Excel 工作表的第一列（A 列），并开启自动折行。
- **单元格图片**：如果表格单元格内包含 `![alt](url)` 网络图片，系统将自动抓取该图片并按比例嵌入对应单元格中。

### 2. 转 PPTX (幻灯片) 时的分页与排版规则
- **封面大标题页**：Markdown 中以一级标题（`# 标题`）开头的段落将独占一页，生成居中展示的演示文稿封面幻灯片。
- **内容幻灯片切页**：二级标题（`## 标题`）作为章节主标题生成新的幻灯片；其后的段落与列表将作为要点垂直排版。
- **高度溢出自动换页**：单张幻灯片累积内容垂直高度超出安全显示范围时，将自动新增幻灯片继续承接后续内容。
- **独立图片幻灯片**：正文中的网络图片 `![alt](url)` 将自动为该图片生成独立的一页幻灯片，居中全景展示。
- **原生表格支持**：Markdown 表格将被直接转换为 PowerPoint 原生表格组件，保留行列结构。

### 3. 转 DOCX (Word) 时的排版规范
- **标题映射**：Markdown 的 `#` ~ `######` 对应 Word 原生样式 `Heading 1` ~ `Heading 6`，生成的文档具备完整的内置大纲目录层级。
- **列表显示**：支持有序列表（带连续数字编号）和无序列表（项目符号 `•`）的缩进展示。
- **代码块样式**：栅格代码块（```）将被格式化为等宽字体（Courier New），附带浅灰色背景底纹与边框线。
- **图文混排**：支持文档内嵌网络图片，自动下载并等比换算显示宽度与高度。

### 4. 文件有效期与持久化说明
- **文件存储权限**：插件借助 FastGPT 的 `file-upload:allow` 权限将 Office 文档持久化上传至 FastGPT 对象存储中。
- **有效期提示**：返回的下载直链可能受 FastGPT 平台对象存储签名时效控制（有效期取决于具体的系统存储配置），建议在工作流回复中提醒用户在会话后及时下载保存到本地。
- **网络图片加载**：文档中引用的图片必须为公网可直接访问的合法 URL。若图片地址失效、防盗链拦截或网络超时，插件将输出友好降级占位提示，不会导致整体文档生成失败。
