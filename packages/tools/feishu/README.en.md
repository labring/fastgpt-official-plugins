# Feishu Custom Bot Webhook

The Feishu Webhook plugin is designed to send message notifications to custom bots in Feishu group chats. By invoking the Feishu bot Webhook endpoint, messages can be delivered to team chats in real time. The plugin supports both plain text messages and structured JSON payloads (such as rich text posts and interactive message cards), facilitating automated alerts and business workflow collaboration.

## Application Scenarios

- **System Monitoring & Alert Notifications**: Push alerts to DevOps or engineering groups in real time when services crash, resources overload, or builds fail.
- **Business Process Reminders & Collaboration**: Notify teams automatically about new ticket creation, CRM lead updates, approval status transitions, or business metric fluctuations.
- **AI Agent Integration & Conversation Summaries**: Forward conversation summaries, critical customer inquiries, or contact leads generated by FastGPT agents to team chats.
- **Scheduled & Automated Workflow Broadcasts**: Broadcast daily data digests, scheduled meeting reminders, or morning briefings to group chats via FastGPT timers and event triggers.

## Feishu Custom Bot Configuration & Webhook Guide

Before using this plugin, create a custom bot in your Feishu group chat and retrieve the **Webhook URL**:

### 1. Add a Custom Bot
1. Open the Feishu desktop or mobile client and go to the target group chat.
2. Click **Group Settings** (the "..." or settings icon in the top right corner) -> select **Bots** -> click **Add Bot**.
3. In the bot gallery, select **Custom Bot** (via Webhook) and click **Add**.

### 2. Configure Basic Bot Information
1. Set the bot's avatar and name (e.g., "Notification Assistant" or "FastGPT Alert Bot").
2. Provide an optional description to help group members identify the bot's purpose.

### 3. Configure Security Settings (Important)
Feishu custom bots support three security verification methods: **Custom Keywords**, **IP Whitelist**, and **Signature Verification**:

- **Signature Verification (Sign)**: **Do NOT enable "Signature Verification"**. This plugin sends standard HTTP POST requests without signature generation. Enabling signature verification will cause Feishu to reject requests with error code `19001` due to missing `timestamp` and `sign` parameters.
- **Custom Keywords** (Recommended): Check this option and define one or more keywords (e.g., "Notification", "Alert"). **Note**: Every message sent must contain at least one configured keyword; otherwise, Feishu will block the message.
- **IP Whitelist**: If FastGPT is hosted on a server with fixed public IP addresses, configure them here for stronger access control.

> **Tip**: In internal testing or trusted network environments, you may configure keywords only or leave security options unconfigured (if allowed by your organization's policy). For production, setting custom keywords or an IP whitelist is recommended.

### 4. Retrieve the Webhook URL
Click **Finish**. Feishu will generate the corresponding **Webhook URL**.
The URL is formatted like:
`https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`

> **Security Note**: Keep this Webhook URL confidential. Anyone with access to this URL can send messages to the group.

## Input Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `hook_url` | String | Yes | Complete Webhook URL of the Feishu custom bot, formatted like `https://open.feishu.cn/open-apis/bot/v2/hook/xxx`. |
| `content` | String | Yes | The message content to send. Accepts a plain text string or a valid JSON string adhering to the Feishu message format (such as rich text `post` or `interactive` cards). |

## Output Results

The plugin returns the response object `result` from the Feishu Webhook API:

| Field | Type | Description |
| :--- | :--- | :--- |
| `result` | Object | The raw JSON response body returned by the Feishu bot API. |
| `result.code` | Number | Status code returned by the Feishu API. Returns `0` on success; returns a non-zero error code on failure (e.g., `19001` for signature errors, `19002` for missing keywords). |
| `result.msg` | String | Status description returned by the Feishu API. Returns `"success"` on success; returns specific error details on failure. |

### HTTP Status Codes (StatusCode)
- **200 OK**: The request successfully reached and was processed by the Feishu server. Check `result.code` to verify message delivery (`code: 0` indicates success).
- **400 / 404 / 500 etc.**: Indicates an invalid Webhook URL, network issues, or temporary server unavailability.

### Success Response Example
```json
{
  "result": {
    "code": 0,
    "msg": "success"
  }
}
```

### Common Error Response Example
```json
{
  "result": {
    "code": 19001,
    "msg": "sign match fail or timestamp is not within one hour from current time"
  }
}
```

## Usage Examples

### 1. Using in a FastGPT Workflow

1. Add the "Feishu Webhook" tool node in the FastGPT workflow editor.
2. Connect it with upstream nodes (e.g., LLM Output, text concatenation, or data processing nodes).
3. Configure the node parameters:
   - **Webhook URL (`hook_url`)**: Enter the Feishu bot Webhook URL, e.g., `https://open.feishu.cn/open-apis/bot/v2/hook/88888888-4444-4444-4444-121212121212`.
   - **Message content (`content`)**: Reference upstream variables (e.g., `{{cdata.text}}`) or provide text/JSON containing configured keywords.

### 2. Message Format Examples

The plugin has built-in smart formatting: plain text strings are automatically wrapped into standard Feishu text messages (`msg_type: "text"`). Valid JSON strings are forwarded directly as request bodies, supporting advanced message types.

#### Example A: Send Plain Text Message (Text)

Pass a plain text string in `content` (ensure it includes your custom keyword if configured):
```text
[Notification] Server CPU utilization exceeded 90%. Please investigate immediately!
```
The plugin automatically formats and dispatches the payload as:
```json
{
  "msg_type": "text",
  "content": {
    "text": "[Notification] Server CPU utilization exceeded 90%. Please investigate immediately!"
  }
}
```

#### Example B: Send Rich Text Message (Post)

Pass a JSON string in `content` with title, multi-line content, and hyperlinks:
```json
{
  "msg_type": "post",
  "content": {
    "post": {
      "zh_cn": {
        "title": "[Notification] Production Deployment Complete",
        "content": [
          [
            {
              "tag": "text",
              "text": "Service version v1.2.0 has been deployed successfully.\n"
            },
            {
              "tag": "a",
              "text": "View Deployment Logs and Metrics Dashboard",
              "href": "https://example.com/deploy"
            }
          ]
        ]
      }
    }
  }
}
```

#### Example C: Send Interactive Message Card (Interactive)

Pass a JSON string representing a Feishu card for a structured alert layout:
```json
{
  "msg_type": "interactive",
  "card": {
    "config": {
      "wide_screen_mode": true
    },
    "header": {
      "title": {
        "tag": "plain_text",
        "content": "[Notification] Service Anomaly Alert"
      },
      "template": "red"
    },
    "elements": [
      {
        "tag": "div",
        "text": {
          "tag": "lark_md",
          "content": "**Module**: Order Payment Service\n**Severity**: Critical\n**Description**: Payment gateway timed out 3 consecutive times."
        }
      },
      {
        "tag": "hr"
      },
      {
        "tag": "action",
        "actions": [
          {
            "tag": "button",
            "text": {
              "tag": "plain_text",
              "content": "Investigate"
            },
            "type": "danger",
            "url": "https://example.com/alerts"
          }
        ]
      }
    ]
  }
}
```

## Important Considerations

1. **Security Settings**:
   - **Do not enable "Signature Verification"** in the bot's security settings. The plugin does not compute HMAC-SHA256 signatures, causing authorization to fail.
   - If **Custom Keywords** are enabled, ensure the `content` (whether plain text or readable text inside JSON) contains at least one configured keyword, or Feishu will block the message.
2. **Rate Limits**:
   - Feishu enforces rate limits on custom bots: **maximum 100 messages per minute per bot**, and **maximum 5 messages per second per group**.
   - If the limit is exceeded, Feishu rejects incoming requests with rate-limiting errors. Add rate limiting or delay nodes in high-frequency notification workflows.
3. **Message Format & Size Limits**:
   - When passing JSON strings, ensure the JSON syntax is valid. Syntax errors will cause the content to be treated and wrapped as plain text.
   - Feishu restricts single message payload sizes (generally up to 30KB). Avoid excessively deep or heavy structures.
4. **Network Connectivity**:
   - The runtime environment executing FastGPT and plugins must be able to reach Feishu Open API domain `https://open.feishu.cn`.
