# 飞书群自定义机器人通知 (Feishu Webhook)

飞书 Webhook 插件用于向飞书群聊自定义机器人发送消息通知。通过调用飞书机器人的 Webhook 接口，实现消息的实时群聊推送。该插件支持纯文本极简发送，以及 JSON 格式的自定义消息（包括富文本、消息卡片等），帮助团队轻松实现自动化告警与流程协同。

## 典型应用场景

- **系统监控与报警通知**：服务异常、宕机警告、构建失败或业务异常时，实时将告警信息推送到飞书运维或开发技术群。
- **业务流程提醒与协作**：当有新工单创建、销售商机跟进、审批流转状态变更或数据指标异动时，自动推送至相关业务群。
- **智能客服与会话联动**：在 FastGPT 智能问答或对话流程中，将 AI 提炼的会话总结、重要咨询线索或用户留资实时抄送群聊。
- **定时与自动化工作流播报**：结合 FastGPT 定时任务或事件触发，自动汇总每日数据报表、会议提醒或早晚报并推送至群。

## 飞书群自定义机器人配置与 Webhook 获取指引

在使用本插件前，需在飞书群中创建自定义机器人并获取对应的 **Webhook 地址 (Webhook URL)**：

### 1. 添加自定义机器人
1. 打开飞书电脑端或移动端，进入目标群聊。
2. 点击右上角的 **群设置**（「...」或「设置」图标） -> 选择 **群机器人** -> 点击 **添加机器人**。
3. 在机器人库列表中选择 **自定义机器人**（通过 Webhook 接入服务），点击 **添加**。

### 2. 配置机器人基本信息
1. 设置机器人头像与名称（例如「系统通知助手」或「FastGPT 报警机器人」）。
2. 输入机器人描述（可选），以便群成员了解机器人的用途。

### 3. 配置安全设置（特别注意）
飞书自定义机器人支持三种安全设置方式：**自定义关键词**、**IP 白名单** 和 **签名校验**：

- **签名校验（加签）**：**请勿勾选「签名校验」**。本插件直接向 Webhook 发起标准 HTTP POST 请求，不包含加签计算逻辑。若勾选签名校验，飞书服务端将因缺少 `timestamp` 和 `sign` 鉴权参数而拦截请求并报错（错误码 `19001`）。
- **自定义关键词**（推荐）：勾选并设置一个或多个关键词（例如「通知」、「告警」）。**注意**：设置后，发送的每条消息内容必须包含至少一个已配置的关键词，否则消息将被拦截。
- **IP 白名单**：若 FastGPT 运行在固定外部公网 IP 服务器上，可配置服务器外网 IP，提供更严格的安全保障。

> **提示**：在内部测试或可信网络环境中，可仅配置关键词或不配置额外限制（若企业权限允许），但生产环境中建议至少配置关键词或 IP 白名单以保障安全。

### 4. 获取 Webhook 地址
配置完成后点击 **完成**，系统将生成对应的 **Webhook 地址**。
格式形如：
`https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`

> **安全提示**：请妥善保管该 Webhook 地址，任何持有该链接的请求均可向群内发送消息，避免泄露造成恶意推送。

## 输入参数

| 参数名 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `hook_url` | 字符串 (String) | 是 | 飞书群自定义机器人的完整 Webhook 地址，格式为 `https://open.feishu.cn/open-apis/bot/v2/hook/xxx`。 |
| `content` | 字符串 (String) | 是 | 需要发送的消息内容。支持传入普通纯文本字符串，或符合飞书开放平台规范的 JSON 格式字符串（如富文本 `post`、卡片 `interactive` 等）。 |

## 输出结果

插件调用飞书 Webhook 接口后，返回响应结果对象 `result`：

| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `result` | 对象 (Object) | 飞书机器人接口返回的完整响应体数据。 |
| `result.code` | 数字 (Number) | 飞书接口返回的状态码。请求成功时为 `0`；失败时返回非 0 错误码（例如 `19001` 签名校验错误、`19002` 缺少关键词等）。 |
| `result.msg` | 字符串 (String) | 飞书接口返回的状态信息。请求成功时为 `"success"`；失败时为具体错误描述原因。 |

### HTTP 状态码说明 (StatusCode)
- **200 OK**：请求成功到达飞书服务器并处理。此时需结合 `result.code` 判断飞书业务层面是否投递成功（`code: 0` 代表成功）。
- **400 / 404 / 500 等**：通常表示 Webhook 地址错误、网络连接异常或飞书服务端暂时不可用。

### 成功响应示例
```json
{
  "result": {
    "code": 0,
    "msg": "success"
  }
}
```

### 常见错误响应示例
```json
{
  "result": {
    "code": 19001,
    "msg": "sign match fail or timestamp is not within one hour from current time"
  }
}
```

## 使用示例

### 1. 在 FastGPT 工作流中使用

1. 在 FastGPT 工作流编排画布中添加「飞书 webhook」节点。
2. 连接前置节点（如「AI 对话」节点、文本拼接或数据处理节点）。
3. 配置节点参数：
   - **机器人 Webhook 地址 (`hook_url`)**：填写飞书群机器人的 Webhook 地址，如 `https://open.feishu.cn/open-apis/bot/v2/hook/88888888-4444-4444-4444-121212121212`。
   - **消息内容 (`content`)**：引用前置节点的变量（如 `{{cdata.text}}`），或直接编写包含关键词的文本或 JSON。

### 2. 消息内容格式示例

插件内置了智能格式化逻辑：若传入的是非 JSON 的普通字符串，插件会自动包装为飞书文本消息 (`msg_type: "text"`)；若传入的是合法 JSON 字符串，则直接作为请求体发送，支持各类高级消息类型。

#### 示例 A：发送纯文本消息 (Text)

直接在 `content` 中传入纯文本字符串（注意若设置了自定义关键词需包含关键词）：
```text
【系统通知】当前服务 CPU 使用率超过 90%，请运维人员尽快处理！
```
插件底层会自动转换为如下格式发送给飞书：
```json
{
  "msg_type": "text",
  "content": {
    "text": "【系统通知】当前服务 CPU 使用率超过 90%，请运维人员尽快处理！"
  }
}
```

#### 示例 B：发送富文本消息 (Post)

在 `content` 中传入富文本 JSON 字符串，支持标题、多段落、超链接等排版：
```json
{
  "msg_type": "post",
  "content": {
    "post": {
      "zh_cn": {
        "title": "【系统通知】线上发布完成",
        "content": [
          [
            {
              "tag": "text",
              "text": "服务版本 v1.2.0 已成功部署上线。\n"
            },
            {
              "tag": "a",
              "text": "点击查看发布日志与监控面板",
              "href": "https://example.com/deploy"
            }
          ]
        ]
      }
    }
  }
}
```

#### 示例 C：发送交互式卡片消息 (Interactive Card)

在 `content` 中传入飞书卡片 JSON 字符串，呈现更美观的告警卡片：
```json
{
  "msg_type": "interactive",
  "card": {
    "config": {
      "wide_screen_mode": true
    },
    "header": {
      "title": {
        "tag": "plain_text",
        "content": "【系统通知】业务异常告警"
      },
      "template": "red"
    },
    "elements": [
      {
        "tag": "div",
        "text": {
          "tag": "lark_md",
          "content": "**告警模块**：订单支付服务\n**异常等级**：Critical\n**详细描述**：连续 3 次支付网关超时，影响用户下单。"
        }
      },
      {
        "tag": "hr"
      },
      {
        "tag": "action",
        "actions": [
          {
            "tag": "button",
            "text": {
              "tag": "plain_text",
              "content": "立即排查"
            },
            "type": "danger",
            "url": "https://example.com/alerts"
          }
        ]
      }
    ]
  }
}
```

## 注意事项

1. **安全设置要求**：
   - 机器人的安全设置中**切勿开启「签名校验」**，否则由于请求未包含签名参数会导致接口鉴权失败。
   - 若开启了「自定义关键词」，请务必确保 `content`（包括纯文本或 JSON 内容内的可读文本）中包含至少一个配置的关键词，否则飞书会拦截消息。
2. **频率限制 (Rate Limits)**：
   - 飞书官方对自定义机器人的发送频率有严格限制：**每个机器人每分钟最多发送 100 条消息**，且**单群内每秒最多发送 5 条消息**。
   - 若超出频率限制，飞书接口将返回限流错误。在高并发推送或批量通知场景下，请在工作流中加入适当的节流（Delay）或分流机制。
3. **消息格式与大小限制**：
   - 传入 JSON 字符串时，请确保 JSON 语法合法且符合飞书开放平台的协议规范；若 JSON 格式有语法错误（如缺少引号或括号），插件将视为纯文本消息发送。
   - 飞书单条消息体大小通常限制在 30KB 以内，富文本及卡片节点不宜过大过深。
4. **网络连通性**：
   - 运行 FastGPT 及插件的服务端环境必须能够正常访问飞书开放平台域名 `https://open.feishu.cn`。
