# MiniMax 语音合成工具集 (MiniMax TTS Tool Set)

MiniMax 语音合成工具集是专为 FastGPT 官方打造的高保真多情绪语音合成（Text-to-Speech, TTS）插件。依托 MiniMax 自研的前沿语音大模型体系（包含 Speech 2.5 与 Speech 02 等核心架构），提供媲美真人的语音表现力、丰富的音色选项、多情绪情感表达以及精细的语速、语调、音量调节能力。

插件内置音频持久化转存机制，在合成完成后自动通过 FastGPT 宿主文件存储能力将音频持久化为高可用直链（MP3 格式），可直接无缝嵌入各类智能体工作流、知识库问答助手及交互式语音应用中。

---

## 典型应用场景

- **智能拟人客服语音播报**：为 AI 客服与售后助手赋予生动、自然的真实语音表达，实时将应答文本合成为流畅语音播放，告别机械单调的播报体验，提升用户沟通好感度。
- **有声书与儿童故事生成**：结合故事剧本文本，自由切换少女、知性成熟女性、青涩少年与精英男声等音色，并叠加欢快、悲伤、惊讶等多重情绪色彩，快速生成沉浸式广播剧、童话故事与有声读物。
- **多模态口播与课件配音**：配合视频生成管线、PPT 智能讲稿或教学微课课件，自动化批量生成清晰标准、发音地道的中英文讲解配音，极大缩短内容创作周期。
- **多情绪拟真语音助理交互**：在语音交互 Agent、角色扮演伴侣、游戏 NPC 中实现生动的双向沟通，根据对话语境动态自适应调整语气、语调与情绪状态。

## 密钥与凭据配置说明

使用本插件需要配置 MiniMax 开放平台的 API 凭据（`apiKey`）。

### 获取渠道与申请指引

1. 访问 [MiniMax 开放平台](https://api.minimax.chat)（海外用户可访问 [MiniMax Global](https://intl.minimaxi.com)）注册并登录账号。
2. 进入管理控制台，点击左侧导航栏的 **「账户管理」->「API Keys」**（或直接访问密钥管理页面）。
3. 点击 **「创建新 API Key」**，复制生成的专属 API Key 字符串（请妥善保管，避免泄露）。
4. 确认账户中具备可用的调用额度或已绑定有效支付方式（平台通常为新注册开发者提供初始免费体验额度）。

### FastGPT 凭据配置

在 FastGPT 插件管理或工具集配置面板中，填写以下配置项：

| 配置项 | 字段名 | 类型 | 是否必填 | 敏感加密 (`isSecret`) | 说明与配置指引 |
| :--- | :--- | :--- | :---: | :---: | :--- |
| **API 密钥** | `apiKey` | 字符串 (`string`) | **是** | 是 (`true`) | MiniMax 开放平台 API 密钥。请求底层接口时将自动作为 `Bearer Token` 添加到请求头 `Authorization` 中用于身份鉴权与额度核销。 |

## 子工具：tts (MiniMax 文本转语音)

### 输入参数说明

在 FastGPT 工作流或智能体工具调用（Tool Call）中，`tts` 子工具支持以下输入参数：

| 参数名 | 字段名 | 类型 | 必填 | 默认/推荐值 | 取值范围 | 说明与示例 |
| :--- | :--- | :--- | :---: | :---: | :--- | :--- |
| **文本内容** | `text` | 字符串 | **是** | 无 | 非空字符串 | **需要转换为语音的文本内容**。建议单次输入在 5,000 字符以内；长篇文本建议在工作流上游先进行文本切分处理。 |
| **模型** | `model` | 枚举字符串 | **是** | `speech-2.5-hd-preview` | 见右侧选项 | **MiniMax 语音合成模型版本**：<br>• `speech-2.5-hd-preview`：**（推荐）** MiniMax 2.5 代高清大模型，具备最高级别的拟真度、语感与细粒度情绪表现力。<br>• `speech-2.5-turbo-preview`：2.5 代极速版，兼顾高保真音质与超低延迟，适合实时人机交互。<br>• `speech-02-hd`：02 代高清版，音质细腻稳定，多语言表现出色。<br>• `speech-02-turbo`：02 代极速版，生成吞吐量大、响应极快。<br>• `speech-01-hd`：01 代高清经典版模型。<br>• `speech-01-turbo`：01 代极速经典版模型。 |
| **音色** | `voice_id` | 枚举字符串 | **是** | `female-shaonv` | 见右侧选项 | **语音合成使用的音色 ID**：<br>• `female-shaonv`：**少女音色**，亲切甜美、元气清澈，推荐用于客服接待、语音助手、童话绘本。<br>• `female-chengshu`：**成熟女性音色**，知性优雅、端庄温和，推荐用于新闻快讯、有声读物、企业培训与科普讲解。<br>• `male-qn-qingse`：**青涩青年音色**，阳光温润、自然真诚，推荐用于日常陪伴、校园解说与休闲播报。<br>• `male-qn-jingying`：**精英男性音色**，沉稳磁性、专业干练，推荐用于商务解说、金融快讯与正式宣传。 |
| **语速** | `speed` | 浮点数 | **是** | `1.0` | `0.5` ~ `2.0` | **语音播放语速**。数值越大语速越快：<br>• `1.0`：正常语速（标准推荐）<br>• `1.2` ~ `1.5`：快节奏资讯播报或快速浏览<br>• `0.8` ~ `0.9`：儿童故事、诗歌朗诵或慢速教学。 |
| **音量** | `vol` | 浮点数 | **是** | `1.0` | `0.1` ~ `10.0` | **语音输出音量**。数值越大音量越大，默认推荐 `1.0`。 |
| **语调** | `pitch` | 整数/浮点数 | **是** | `0` | `-12` ~ `12` | **语音音高语调**（以半音为单位微调）。数值越大语调越高，负值语调越低沉：<br>• `0`：标准自然语调<br>• `+1` ~ `+3`：欢快活泼或年轻感<br>• `-1` ~ `-3`：成熟稳重或严肃感。 |
| **情绪** | `emotion` | 枚举字符串 | 否 | `""` (无) | 见右侧选项 | **生成语音的情绪风格**（在 `speech-2.5` 和 `speech-02` 上表现最佳）：<br>• `""`（留空）：自然中立，标准语气<br>• `happy`：欢快高兴、喜悦热情<br>• `sad`：悲伤低落、沉郁哀婉<br>• `angry`：愤怒严肃、情绪激昂<br>• `fearful`：害怕恐惧、紧张小心<br>• `disgusted`：厌恶反感、嫌弃不悦<br>• `surprised`：惊讶诧异、意外惊奇<br>• `calm`：平静从容、温和理智。 |
| **英文规范化** | `english_normalization` | 布尔值 | **是** | `true` | `true` / `false` | **英文文本发音规范化**。开启后可显著提升英文数字、缩写、度量衡符号及混合句型的发音连贯性与准确率，但会微幅增加合成耗时。默认推荐开启（`true`）。 |

### 输出结果说明

`tts` 子工具在语音合成成功后返回以下输出字段：

| 字段名 | 类型 | 说明与示例 |
| :--- | :--- | :--- |
| `audioUrl` | 字符串 (`string`) | **合成音频的持久化访问直链 URL**。音频格式为标准 MP3，通过 FastGPT 宿主文件上传服务转存至对象存储中，具有持久有效性与高公网可用性。 |

#### 输出 JSON 示例

```json
{
  "audioUrl": "https://fastgpt.example.com/api/system/file/view?fileId=66b4d32e92c43801f98d1a2f&filename=minimax_tts.mp3"
}
```

> **音频持久化转存机制说明**：
>
> 插件在 `manifest` 中声明了 `permission: ["file-upload:allow"]` 宿主权限。MiniMax T2A v2 接口返回十六进制编码的原始音频流后，插件会自动将其还原为二进制 Buffer，并调用 FastGPT 宿主环境的 `uploadFile` 接口写入存储桶，生成可公网稳定访问且长期有效的直链 URL（`audioUrl`）。若在无 FastGPT 运行时的本地独立测试环境中调用，则会自动降级返回可直接播放的 Base64 Data URL。

## 典型工作流编排示例

在 FastGPT 应用工作流中，将 MiniMax TTS 与大语言模型（LLM）节点组合，即可轻松构建「**用户提问 -> LLM 智能生成应答 -> MiniMax 高保真拟真发音 -> 消息节点播放音频**」的闭环端到端交互：

### 1. 工作流拓扑架构

```mermaid
flowchart TD
    A[用户问题 / 语音输入] --> B[AI 对话 / LLM 节点]
    B -->|应答文本 {{LLM.text}}| C[MiniMax 文本转语音 tts]
    C -->|音频持久化直链 {{audioUrl}}| D[指定回复 / 文本输出节点]
```

### 2. 详细配置步骤

1. **添加 AI 对话节点**：
   - 接收用户输入的问题或对话内容。
   - 配置系统提示词（System Prompt），例如：
     ```markdown
     你是一位专业热情的智能助手。请针对用户的提问给出清晰简练、富有感染力的口语化回答（控制在 200 字以内，避免过于书面化），方便后续转为语音播报。
     ```

2. **添加「minmax 文本转语音 (`tts`)」节点**：
   - 将 `text` 参数引用绑定为 AI 对话节点的输出变量：`{{LLM.text}}`。
   - 模型（`model`）选择：`speech-2.5-hd-preview`（拟真度最高）或 `speech-2.5-turbo-preview`（延迟更低）。
   - 音色（`voice_id`）：根据助手人设选择，如 `female-shaonv`（甜美助手）或 `male-qn-jingying`（商务助手）。
   - 情绪（`emotion`）：根据对话基调选择，例如日常问候可选择 `happy`，理性解答可保持 `calm` 或留空。
   - 语速（`speed`）与音量（`vol`）：保持默认 `1.0`。
   - 语调（`pitch`）：保持默认 `0`。
   - 英文规范化（`english_normalization`）：设为 `true`。

3. **添加「指定回复」或「文本输出」节点**：
   - 在回复内容框中，同时输出文字答案与音频播放器控件：
     ```markdown
     {{LLM.text}}

     <audio src="{{tts.audioUrl}}" controls></audio>
     ```
   - 或者使用简洁的 Markdown 超链接形式：
     ```markdown
     {{LLM.text}}

     [🔊 点击播放语音回答]({{tts.audioUrl}})
     ```
   - 用户在聊天界面接收到回答时，既能阅读文字，又可直接点击原生播放器收听流畅自然的拟人语音。

## 注意事项与常见问题

1. **单次合成文本长度建议**：MiniMax T2A v2 接口对单次请求文本长度有上限约束（若超出 Token 限制将返回错误码 `1039`）。建议单次合成文本控制在 **5,000 字符** 以内。对于小说长篇、长篇报告等大文本，建议在工作流上游配合「文本切分」节点按句或段落分批转换。
2. **接口速率与并发限制 (Rate Limit)**：MiniMax 开放平台对不同开发者层级设有 QPS（每秒请求数）与并发连接数上限。若请求过于密集，可能触发 `1002`（请求频率超限）或 `1041`（连接数限制）。在批量生产音频或高并发业务场景中，建议配置队列或适当引入重试机制。
3. **账户余额与可用额度**：调用语音合成 API 会消耗 MiniMax 账户中的额度。请确保在 [MiniMax 开放平台](https://api.minimax.chat) 账户中有充足余额；若余额不足，接口将返回错误码 `1008`（余额不足）。
4. **内容合规安全检测**：MiniMax 接口内置严格的安全合规审查策略。若输入的待合成文本包含敏感违规内容，将触发错误码 `1026`（输入内容涉敏）或 `1027`（输出内容涉敏）并终止合成，请确保输入文本合法合规。
5. **情绪参数适用范围**：情绪（`emotion`）在 `speech-2.5` 与 `speech-02` 系列模型中具备最出色的自然度表现。若留空 `""`，模型将默认以标准平稳的中立语调发音。

### 常见错误码速查表

| 错误码 | 错误描述 | 排查与解决建议 |
| :---: | :--- | :--- |
| `1000` | 未知错误/系统默认错误 | MiniMax 服务端临时异常，建议稍后重试。 |
| `1001` | 请求超时 | 网络抖动或生成耗时过长，检查网络连通性或减少单次合成文本量。 |
| `1002` | 请求频率超限 (Rate Limit) | 请求 QPS 超过平台配额，降低调用频次或在开放平台申请提升配额。 |
| `1004` | 未授权/Token不匹配/Cookie缺失 | API Key 缺失或无效，请检查 FastGPT 凭据中的 `apiKey` 是否填写正确。 |
| `1008` | 余额不足 | 账户充值额度已耗尽，请前往 MiniMax 开发者控制台充值。 |
| `1026` / `1027` | 输入/输出内容涉敏 | 文本触发平台内容安全策略，请调整输入文本规避敏感词。 |
| `1039` | Token 限制 | 单次请求文本长度超出限制，请对文本进行截断或分块处理。 |
| `1041` | 连接数限制 | 并发请求数超出账户上限，请优化并发量。 |
| `2013` | 参数错误 | 请求参数不合法，检查 `speed`、`vol`、`pitch` 等数值是否在合法区间内。 |
| `2049` | 无效的 API Key | 填写的 API Key 不存在或已被吊销，请在控制台重新生成。 |
