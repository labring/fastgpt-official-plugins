# 必优 ChatPPT 一键生成 PPT (ChatPPT)

ChatPPT 是由必优科技（Biyou AI）推出的智能演示文稿生成服务。本插件为 FastGPT 提供了开箱即用的 AI 一键生成 PPT 演示文稿能力。

借助必优强大的自然语言理解与排版渲染引擎，本插件可将用户输入的文本描述、演讲提纲或大模型生成的结构化大纲快速转化为设计美观、排版专业、结构完整的演示文稿，并返回集成了在线预览、放映演示、二次编辑与 PPTX 文件下载功能的直链地址。

---

## 典型应用场景

- **职场述职与汇报 PPT 一键生成**：将日常周报、月度总结、季度绩效或年终述职要点一键转化为精美幻灯片，大幅削减排版与配图耗时。
- **商业计划书与方案草稿**：基于商业模式、产品规划、市场洞察或融资策划方案快速生成高水准的商业路演和项目提案初稿。
- **教育培训与公开课课件快速生成**：将课程知识要点、培训大纲、学术讲解材料快速排版为图文并茂的教学演示课件。
- **会议演讲文稿演示化**：将研讨会发言稿、学术演讲要点或会议主旨纪要自动提炼并生成适合现场大屏投屏的演示幻灯片。

## 密钥配置说明

使用本插件需要配置必优开放平台的 API 密钥（`apiKey`）。

### 获取渠道

1. 访问 [必优开放平台 / ChatPPT 开发者中心](https://chatppt.yoo-ai.com)（或必优科技官网 [https://www.yoo-ai.com](https://www.yoo-ai.com)）注册并登录账号。
2. 进入控制台或开发者中心，创建应用并申请 API 密钥（`API Key`）。
3. 复制生成的密钥字符串（请妥善保管）。
4. 确认账户中拥有可用的生成点数或额度（新用户享有初始体验额度，正式业务调用请按需采购额度）。

### 配置方式

在 FastGPT 插件配置或工作流节点的密钥管理中配置以下字段：

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `apiKey` | 字符串 (`string`) | 是 | 必优科技开放平台 API Key。请求时作为 `Bearer Token` 用于接口鉴权与账户额度扣减。 |

---

## 输入参数

| 参数名 | 字段类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `text` | 字符串 (`string`) | 是 | 无 | **演示文稿描述文本或结构化大纲**。<br>用于生成 PPT 的核心内容。支持传入自然语言主题描述（如“2025年人工智能技术发展与商业落地展望”），或 Markdown 格式的结构化大纲（包含多级标题、核心论点及逐页要点）。结构越完整清晰，生成的幻灯片质量与贴合度越高。 |
| `color` | 字符串 (`string`) | 否 | 无 | **演示文稿主题色**。<br>指定幻灯片的主色调与设计风格。支持填写**标准十六进制色值**（如科技蓝 `#1E88E5`、商务绿 `#2E7D32`、活力红 `#C62828`、温暖橙 `#EF6C00`、典雅紫 `#6A1B9A`、沉稳深灰 `#37474F`）或**常用英文颜色词**（如 `blue`、`green`、`red`、`orange`、`purple`）。若留空，必优智能排版引擎将根据内容主题自动匹配最适宜的色彩方案。 |

---

## 输出结果

| 字段名 | 字段类型 | 说明 |
| --- | --- | --- |
| `preview_url` | 字符串 (`string`) | **PPT 在线预览与交互链接**。<br>指向必优云端生成的演示文稿。用户在浏览器中点击直链即可免安装完成：<br>1. **在线完整预览**：逐页查看幻灯片版式、排版与配图；<br>2. **全屏在线放映**：直接进行演讲与汇报演示；<br>3. **云端二次编辑**：调整文本内容、更换配色与排版布局；<br>4. **本地文件导出**：直接下载 `.pptx` 格式的 PowerPoint 原文件。 |

### 输出示例

```json
{
  "preview_url": "https://saas.api.yoo-ai.com/preview/ppt?id=c7a31b8e-9d24-4f81-8e56-123456789abc"
}
```

## 典型工作流编排示例

通过 FastGPT 工作流编排，可构建完整的 **「需求输入 -> 大模型大纲生成 -> ChatPPT 一键渲染 -> 在线查看/下载」** 智能 PPT 助手：

```mermaid
flowchart LR
    A["用户输入节点<br/>(输入主题与配色偏好)"] --> B["大模型节点 (LLM)<br/>(生成结构化 PPT 大纲)"]
    B --> C["ChatPPT 插件节点<br/>(生成在线演示文稿)"]
    C --> D["回复输出节点<br/>(提供在线预览与下载链接)"]
```

### 节点编排步骤

1. **用户输入节点**：接收用户关于制作 PPT 的主题、受众与风格要求（例如：“请为我制作一份新能源汽车行业 2025 年出海战略汇报，主题色偏好科技蓝”）。
2. **大模型 (LLM) 节点**：
   - **System Prompt**：
     ```text
     你是一个专业的商业汇报演示策划专家。请根据用户的需求，输出包含封面标题、副标题、目录、4-6 个主体章节及总结展望的 Markdown 结构化 PPT 大纲。
     要求：
     1. 使用 # 表示 PPT 总标题，## 表示各页标题，- 列表表示单页内的核心要点。
     2. 保持逻辑层次分明、论据翔实、语言干练。
     ```
   - **输出**：生成格式规整的 PPT 大纲文本，并提取对应的颜色代码（如 `#1E88E5`）。
3. **ChatPPT 工具节点**：
   - 将 LLM 节点输出的大纲内容绑定至 `text` 参数。
   - 将颜色变量（如 `#1E88E5`）绑定至 `color` 参数。
4. **指定回复 / 对话输出节点**：
   - 引用 ChatPPT 节点的 `preview_url` 输出变量，以富文本形式反馈给用户：
     ```markdown
     您的演示文稿已生成完毕！

     🔗 **[点击在线预览 / 放映 PPT]({{chatPPT.preview_url}})**

     > 提示：在打开的页面中，您可以直接全屏放映，或点击右上角下载保存 `.pptx` 文件至本地进一步编辑。
     ```

## 注意事项

1. **生成耗时说明**：PPT 生成涵盖大模型语义理解、模板匹配、图文素材渲染及版式装配等多道工序，通常耗时约 10~30 秒。请在上游 FastGPT 工作流或调用端合理设置超时等待时间。
2. **账号额度与鉴权**：调用本插件需要有效的必优开放平台 API Key。每次成功生成均会扣减相应账户的生成额度。若调用失败，请优先检查 API Key 是否有效以及账户可用额度是否充足。
3. **网络访问要求**：FastGPT 运行环境需能够正常访问必优开放平台接口域名 `https://saas.api.yoo-ai.com`；生成的 `preview_url` 需终端用户浏览器能正常访问公网。
4. **提示词与大纲优化**：输入的内容层次越分明，生成的幻灯片版式越专业。推荐在 `text` 中采用 Markdown 层级标题与列表要点，避免仅传入单句极简文本。
5. **文件保存建议**：`preview_url` 为必优云端在线预览与编辑链接，建议用户在生成后及时在线查看，并根据需要导出下载本地 `.pptx` 文件归档保存。
