# 企业微信群机器人通知 (WeWork Webhook)

企业微信 Webhook 插件用于向企业微信群聊中的自定义机器人发送文本消息。通过调用企业微信官方提供的 Webhook 接口，实现与群聊的实时通信与消息推送。

> **重要说明**：根据企业微信官方规范，自定义机器人**仅支持企业微信内部群**（即群成员均为同一企业员工的内部群聊），外部群、跨企业互联群以及包含微信外部联系人的群聊暂不支持添加与使用自定义机器人。

## 应用场景

- **内部运维告警与监控通知**：当系统监控或工作流捕获到服务异常、性能告警或部署失败时，第一时间将警报推送到企业微信运维或研发群。
- **业务流程与审批提醒**：如新工单分配、OA 审批流转状态变更、数据指标异动、日常巡检通知等。
- **智能客服与会话联动**：在 FastGPT 智能问答或对话流程中，将长文本会话总结、重要客户咨询线索或需要人工跟进的问题实时抄送至内部协同群。
- **自动化工作流协作**：结合 FastGPT 定时任务或外部 Webhook 事件触发，自动汇总日常信息、早晚报并推送到群聊。

## 企业微信群自定义机器人配置与 Webhook 获取指引

在使用本插件前，需在企业微信内部群中添加自定义机器人并获取其专属的 **Webhook 地址 (Webhook URL)**。具体操作建议在企业微信电脑端（PC / Mac）完成：

### 1. 进入群设置
1. 打开企业微信电脑端，进入需要接收通知的目标**内部群聊**。
2. 点击群聊窗口右上角的 **群设置** 图标（「...」或管理面板）。

### 2. 添加群机器人
1. 在群设置面板中找到 **群机器人** 选项。
2. 点击 **添加机器人**（若群内已有机器人，可点击右上角「+」或「添加」）。
3. 在弹出的机器人库中选择 **新创建一个机器人**。

### 3. 配置机器人信息
1. 为机器人设置 **名称**（例如「系统通知助手」、「运维告警机器人」）并上传自定义头像（可选）。
2. 点击 **添加**，系统将即刻创建机器人并生成专属配置。

### 4. 获取 Webhook 地址
1. 创建成功后，界面将展示该机器人的专属 **Webhook 地址**，格式形如：
   ```text
   https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   ```
2. 点击右侧的 **复制** 按钮保存该地址。后续在 FastGPT 节点中作为 `webhookUrl` 参数填入即可。

> **安全提示**：Webhook 地址中的 `key` 是机器人的唯一身份鉴权凭证。拥有该 URL 的任何人均可向群内发送消息，请妥善保管，避免提交至公共代码仓库或公开泄露。

## 输入参数

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `webhookUrl` | 字符串 (String) | 是 | 企业微信内部群机器人的完整 Webhook 地址，形如 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxx`。兼容旧版字段名 `企微机器人地址`。 |
| `message` | 字符串 (String) | 是 | 需要推送到企业微信群的消息文本内容。兼容旧版字段名 `发送的消息`。 |

> **字段兼容性说明**：插件支持标准英文键名（`webhookUrl`、`message`）与旧版中文键名（`企微机器人地址`、`发送的消息`）。插件内部已做兼容性转换，两个版本参数均可生效，推荐在 FastGPT 工作流编排中统一使用标准英文键名。

## 输出结果

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| - | 对象 (Object) | 发送成功返回空对象 `{}`。若推送失败或参数校验未通过，将直接抛出异常并包含企业微信接口返回的详细错误信息。 |

## 使用示例

### 在 FastGPT 工作流中使用

1. 在 FastGPT 应用工作流编排中添加 **企业微信 webhook** 工具节点。
2. 连接前置节点（如「AI 对话」输出、「文本加工」节点或「条件分支」）。
3. 节点参数配置示例：
   - **Webhook URL (`webhookUrl`)**：`https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=693a91f6-7xxx-4bc4-97a0-0ec2cd54xxxx`
   - **发送的消息 (`message`)**：`{{cdata.text}}`（或引用上游节点的文本变量）

### 请求 Payload 格式参考

插件底层向企业微信 Webhook 接口发送的 HTTP POST 请求体为纯文本 JSON 格式：

```json
{
  "msgtype": "text",
  "text": {
    "content": "【系统告警】生产环境数据库连接数超过阈值 (85%)，请及时排查！"
  }
}
```

## 注意事项

1. **仅支持内部群**：企业微信自定义机器人目前仅支持企业内部群，包含外部微信联系人的外部群、跨企业群无法添加自定义机器人。
2. **频率限制（频控）**：企业微信官方对每个自定义机器人有严格的发送频率限制：**每个机器人每分钟最多发送 20 条消息**。如超出限制会被系统拦截并限制发送。对于高并发推送场景，建议在工作流中增加防抖/节流控制，或配置多个机器人分流轮询推送。
3. **消息格式与文本长度**：
   - 当前版本推送消息为 `text` 纯文本格式。
   - 企业微信官方限制单条文本内容最长不超过 **2048 个字节**（UTF-8 编码，约 680 个中文字符）。若消息内容超出该限制，调用企微 API 会返回错误 `40058: message content text limit`。如需发送大段内容，请先在工作流中进行截断或拆分分段发送。
4. **网络访问要求**：FastGPT 插件运行环境需能够正常访问企业微信官方 API 域名 `https://qyapi.weixin.qq.com`（端口 443）。若所处内网环境配置了防火墙或代理白名单，请确认该域名已放行。
