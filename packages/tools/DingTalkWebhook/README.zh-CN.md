# 钉钉自定义机器人通知 (DingTalk Webhook)

钉钉 Webhook 插件用于向钉钉群自定义机器人发送文本消息。通过调用钉钉机器人的 Webhook 接口并自动完成 HMAC-SHA256 加签鉴权，实现群聊消息的实时推送。

## 应用场景

- **报警与监控通知**：当系统监控或工作流捕获到异常状态时，第一时间推送到钉钉运维或研发群。
- **业务流程提醒**：如新工单创建、审批流转状态变更、数据指标异动提醒。
- **智能客服与会话联动**：在 FastGPT 智能问答或对话流程中，将总结报告、重要咨询线索实时抄送群聊。
- **自动化工作流协作**：结合 FastGPT 定时任务或事件触发，自动汇总日常信息并发送至群。

## 钉钉自定义机器人配置与密钥指引

在使用本插件前，需在钉钉群中创建自定义机器人并获取 **Webhook URL** 和 **加签密钥（Secret）**：

### 1. 添加自定义机器人
1. 打开钉钉电脑端或手机端，进入目标群聊。
2. 点击右上角的 **群设置**（「...」或「群设置」图标） -> **智能群助手** -> **添加机器人**。
3. 在机器人库中选择 **自定义（通过 Webhook 接入自定义服务）**，点击 **添加**。

### 2. 配置安全设置（加签）
1. 设置机器人头像与名称（例如「系统通知助手」）。
2. **安全设置** 中必须勾选 **加签**：
   - 勾选后系统会生成以 `SEC` 开头的密钥字符串（如 `SEC123456...`）。
   - 本插件内置 HMAC-SHA256 加签机制，使用该密钥计算签名以保证接口调用的安全与稳定。
3. 点击 **完成**，系统将生成对应的 **Webhook 地址**。

### 3. 获取配置参数
- **Webhook 地址 (Webhook URL)**：格式形如 `https://oapi.dingtalk.com/robot/send?access_token=xxxxxx`。
- **加签密钥 (Secret)**：页面显示的密钥字符串，形如 `SECxxxxxx`。

> **提示**：请妥善保管机器人的 Webhook 地址与加签 Secret，避免泄露造成恶意推流。

## 输入参数

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `webhookUrl` | 字符串 (String) | 是 | 钉钉群自定义机器人的完整 Webhook 地址，需包含 `access_token`。兼容旧版参数名 `钉钉机器人地址`。 |
| `secret` | 字符串 (String) | 是 | 钉钉自定义机器人安全设置中配置的「加签」密钥（通常以 `SEC` 开头）。兼容旧版参数名 `加签值`。 |
| `message` | 字符串 (String) | 是 | 需要发送到钉钉群的消息文本内容。兼容旧版参数名 `发送的消息`。 |

> **兼容性说明**：插件支持标准英文键名（`webhookUrl`、`secret`、`message`）与旧版中文键名（`钉钉机器人地址`、`加签值`、`发送的消息`），推荐统一使用标准英文键名。

## 输出结果

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| - | 对象 (Object) | 发送成功返回空对象 `{}`。若推送失败或参数校验不通过，将抛出异常并提示具体错误原因。 |

## 使用示例

### 在 FastGPT 工作流中使用

1. 在 FastGPT 应用编排中添加「钉钉 webhook」工具节点。
2. 连接前置节点（如 LLM 输出、文本拼接或条件分支）。
3. 节点参数配置示例：
   - **Webhook URL**：`https://oapi.dingtalk.com/robot/send?access_token=8888888888888888`
   - **加签值 (Secret)**：`SEC8888888888888888`
   - **发送的消息 (Message)**：`{{cdata.text}}`（或引用上游节点的文本变量）

### 请求 Payload 格式参考

插件底层向钉钉服务器发送的 JSON 数据格式如下：

```json
{
  "msgtype": "text",
  "text": {
    "content": "系统通知：服务器 CPU 使用率超过 90%，请及时排查！"
  }
}
```

## 注意事项

1. **加签机制要求**：
   - 本插件会自动根据传入的 `secret` 和当前系统时间戳 `${timestamp}\n${secret}` 通过 HMAC-SHA256 算法生成签名，并将 `timestamp` 与 `sign` 参数附加至 Webhook 请求 URL 中。
   - 钉钉要求时间戳与钉钉服务器时间相差不能超过 1 小时。
   - 机器人安全设置中**必须开启「加签」**。若仅勾选「自定义关键词」或「IP 地址段」而未启用「加签」，签名校验将无法通过并导致消息发送失败。
2. **频率限制**：
   - 钉钉官方对单个自定义机器人的推送频率有限制：**每个机器人每分钟最多发送 20 条消息**。如超出限制会被限流 10 分钟。对于高并发推送场景，建议在工作流中进行频率控制或配置多个机器人分流。
3. **消息格式与长度限制**：
   - 当前版本推送消息为 `text` 纯文本格式。
   - 钉钉文本消息长度限制单条通常不超过 20000 个字符。
4. **网络要求**：
   - 运行 FastGPT 插件的环境需要能够正常访问钉钉开放平台接口域名 `https://oapi.dingtalk.com`。
