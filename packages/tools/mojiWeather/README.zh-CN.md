# 墨迹天气工具集 (Moji Weather)

墨迹天气工具集是一款为 FastGPT 打造的高精度气象数据服务插件，集成墨迹天气专业气象预报能力，支持中国大陆多级行政区划（省、市、区、县）的精细化气象查询，以及灵活的自定义多天日期范围天气预报检索。

本插件为 FastGPT 智能体应用提供了开箱即用的气象感知能力。通过智能模糊匹配城市与区县编码，一键获取包括昼夜天气状况、最高/最低温度、相对湿度、风向风力、降水概率、降水量、紫外线指数、日出日落及月相在内的数十项全维度气象指标，为出行规划、智能硬件联动、活动筹备等场景提供强大的气象数据支撑。

---

## 典型应用场景

- **智能出行与旅游路线规划助手**：根据用户输入的行程计划（如“五一假期去杭州西湖玩三天”），大模型自动解析出发地与目的地城市及日期范围，调用本工具批量检索未来天气，针对降雨天气智能调整室内/室外游览顺序，生成贴合天气的出行路线。
- **日常早安天气播报与生活顾问**：结合定时触发器与工作群机器人（钉钉/飞书/企业微信），每天早晨自动查询目标区县的当日天气，由大模型根据紫外线指数（`uvi`）、昼夜温差与降水概率（`pop`）智能生成富有温度的穿衣指南、防晒与带伞提醒。
- **户外施工与大型活动安全预警**：工程施工、户外体育赛事、音乐节或户外婚礼策展应用中，系统定期追踪目标地点的风力等级（`windLevelDay`）、降水量（`qpf`）与雷暴天气预报，一旦指标超标自动触发停工避险或防雨预警流程。
- **智能家居与温控晾晒自动化**：作为家庭智能中控的前置感知工具，依据未来 24-48 小时内的相对湿度（`humidity`）与降水概率，联动控制室内除湿机、空调设定温度以及阳台智能晾衣架的自动升降与收纳。

## 密钥配置说明

使用本插件需要配置墨迹天气商业数据服务的 API 密钥（`apiKey`）。

### 获取渠道

本插件底层调用墨迹天气全国 15 天天气预报服务，通过 `Authorization: APPCODE <apiKey>` 进行请求鉴权。

1. 访问 **[阿里云云市场](https://market.aliyun.com/)** 或 **[墨迹天气开放平台](https://developer.moji.com/)**。
2. 搜索并选择 **「墨迹天气 全国天气预报 15 天查询」** 或相关天气 API 服务商品。
3. 注册/登录账号并购买服务（云市场通常提供免费试用资源包或规格套餐）。
4. 在阿里云控制台的「云市场」->「已购买服务」中找到该商品，复制其对应的 **AppCode**。
5. 将复制的 AppCode 作为 `apiKey` 配置到 FastGPT 插件设置中。

### 配置方式

在 FastGPT 的工具集密钥管理或节点配置界面中填写以下字段：

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `apiKey` | 字符串 (`string`) | 是 | 墨迹天气 API 密钥（即阿里云云市场服务 AppCode）。调用外部天气接口时将用于请求头身份鉴权。 |

## 子工具列表

本工具集目前包含以下子工具：

- **`tool`（每日天气 / Daily Weather）**：根据输入的省、市、区县及指定的起止日期范围，查询目标区域逐日的详细天气预报数据。

## 子工具：每日天气 (`tool`)

### 输入参数

| 参数名 | 字段类型 | 必填 | 默认值 | 说明与示例 |
| --- | --- | --- | --- | --- |
| `province` | 字符串 (`string`) | 否（条件必填） | 无 | **省份名称**。例如：`"浙江省"`、`"北京市"`、`"广东省"`。支持自动裁剪“省/自治区/特别行政区”后缀进行模糊匹配。 |
| `city` | 字符串 (`string`) | 否（条件必填） | 无 | **城市名称**。例如：`"杭州市"`、`"北京市"`、`"广州市"`。支持自动裁剪“市/地区/自治州/盟”后缀。 |
| `towns` | 字符串 (`string`) | 否（条件必填） | 无 | **区县名称**。例如：`"余杭区"`、`"朝阳区"`、`"天河区"`。支持自动裁剪“区/县/旗/市辖区”后缀。 |
| `start_time` | 字符串 (`string`) | 是 | 无 | **预报查询起始日期**。格式严格要求为 `YYYY-MM-DD`，例如：`"2025-05-01"`。仅返回日期大于等于该天的数据。 |
| `end_time` | 字符串 (`string`) | 是 | 无 | **预报查询截止日期**。格式严格要求为 `YYYY-MM-DD`，例如：`"2025-05-03"`。仅返回日期小于等于该天的数据。 |

> **注意**：
> - `province`、`city`、`towns` 三者中**必须至少填写一个**。
> - 建议同时提供 `city` 与 `towns`（或 `province` 与 `city`），以避免同名区县（例如北京“朝阳区”与长春“朝阳区”）发生匹配歧义。

### 输出结果

执行成功后，插件返回包含天气数组的对象：`{ "data": [ ... ] }`。数组中的每个元素包含目标日期的完整气象预报：

| 字段名 | 字段类型 | 含义 | 说明与示例 |
| --- | --- | --- | --- |
| `predictDate` | 字符串 (`string`) | 预报日期 | 对应预报的具体日期，格式为 `YYYY-MM-DD`，如 `"2025-05-01"`。 |
| `conditionDay` | 字符串 (`string`) | 白天天气状况 | 白天天气现象描述，如 `"晴"`、`"多云"`、`"雷阵雨"`、`"中雨"`、`"阴"`。 |
| `conditionNight` | 字符串 (`string`) | 夜间天气状况 | 夜间天气现象描述，如 `"多云"`、`"阴"`、`"阵雨"`、`"晴"`。 |
| `conditionIdDay` | 字符串 (`string`) | 白天天气代码 | 白天天气现象数字代码，如 `"0"`（晴）、`"1"`（多云）、`"2"`（阴）。 |
| `conditionIdNight` | 字符串 (`string`) | 夜间天气代码 | 夜间天气现象数字代码。 |
| `tempDay` | 字符串 (`string`) | 白天最高温度 | 白天最高气温（单位：℃），如 `"26"`。 |
| `tempNight` | 字符串 (`string`) | 夜间最低温度 | 夜间最低气温（单位：℃），如 `"16"`。 |
| `humidity` | 字符串 (`string`) | 相对湿度 | 预报平均相对湿度百分比（%），如 `"65"`。 |
| `pop` | 字符串 (`string`) | 降水概率 | 降水发生概率百分比（%），如 `"20"` 表示 20% 概率降水。 |
| `qpf` | 字符串 (`string`) | 定量降水量 | 定量降水预报值（单位：mm），如 `"0.0"` 或 `"15.2"`。 |
| `uvi` | 字符串 (`string`) | 紫外线指数 | 紫外线强度指数（0-15），如 `"7"`（强）。 |
| `windDirDay` | 字符串 (`string`) | 白天风向 | 白天主导风向描述，如 `"东南风"`、`"微风"`、`"北风"`。 |
| `windDirNight` | 字符串 (`string`) | 夜间风向 | 夜间主导风向描述，如 `"南风"`、`"无持续风向"`。 |
| `windLevelDay` | 字符串 (`string`) | 白天风力等级 | 白天风力等级，如 `"3"`（3 级风）。 |
| `windLevelNight` | 字符串 (`string`) | 夜间风力等级 | 夜间风力等级，如 `"2"`。 |
| `windSpeedDay` | 字符串 (`string`) | 白天风速 | 白天预报风速（单位：m/s），如 `"4.2"`。 |
| `windSpeedNight` | 字符串 (`string`) | 夜间风速 | 夜间预报风速（单位：m/s），如 `"2.8"`。 |
| `windDegreesDay` | 字符串 (`string`) | 白天风向角度 | 白天风向度数（0°~360°），如 `"135"`。 |
| `windDegreesNight` | 字符串 (`string`) | 夜间风向角度 | 夜间风向度数（0°~360°），如 `"180"`。 |
| `sunrise` | 字符串 (`string`) | 日出时间 | 当地日出时间，格式为 `HH:mm`，如 `"05:18"`。 |
| `sunset` | 字符串 (`string`) | 日落时间 | 当地日落时间，格式为 `HH:mm`，如 `"18:52"`。 |
| `moonphase` | 字符串 (`string`) | 月相 | 预报日期对应的月相名称，如 `"盈凸月"`、`"满月"`、`"新月"`。 |
| `moonrise` | 字符串 (`string`) | 月出时间 | 当地月升时间，如 `"14:20"`。 |
| `moonset` | 字符串 (`string`) | 月落时间 | 当地月落时间，如 `"02:35"`。 |
| `updatetime` | 字符串 (`string`) | 数据更新时间 | 气象台发布该预报数据的时间戳，如 `"2025-05-01 07:00:00"`。 |

## 典型工作流编排示例

### 场景：出行天气助手与穿衣带伞建议

通过 FastGPT 工作流编排，实现从“用户自然语言提问”到“气象查询”，再到“贴心生活建议”的闭环链路：

```
[用户提问]
  │ （例如：“我这周末想去杭州余杭玩两天，天气怎么样，需要带厚衣服或者雨伞吗？”）
  ▼
[LLM 信息抽取节点 / 意图识别]
  │ 提取参数：
  │ - city: "杭州市"
  │ - towns: "余杭区"
  │ - start_time: "2025-05-10"
  │ - end_time: "2025-05-11"
  ▼
[墨迹天气工具节点 (mojiWeather -> tool)]
  │ 传入参数并调用墨迹天气 API
  │ 输出结构化天气数据数组 data
  ▼
[AI 总结与生活建议节点]
  │ 系统提示词输入天气数据，并指引模型：
  │ 1. 总结周末期间白天气温与昼夜温差（结合 tempDay、tempNight）
  │ 2. 根据天气状况（conditionDay/Night）和降水概率（pop）明确提示是否需要带伞
  │ 3. 结合紫外线指数（uvi）提供防晒建议
  ▼
[输出回复给用户]
```

#### 工作流配置要点：
1. **意图抽取节点**：引导模型输出严格符合规范的 JSON 结构，并确保 `start_time` 和 `end_time` 转换为标准的 `YYYY-MM-DD` 格式。
2. **天气工具节点**：在节点输入中绑定上游抽取出的 `city`、`towns`、`start_time`、`end_time` 变量。
3. **最终回复节点**：将 `mojiWeather.data` 作为参考上下文注入到下游大模型节点，利用其强大的语言表达能力为用户提供条理清晰、有温度的出行助手服务。

## 注意事项

1. **日期格式规范**：`start_time` 和 `end_time` 必须严格遵循 `YYYY-MM-DD`（如 `2025-05-01`）的标准日期格式。若格式不正确或为空，将导致日期过滤失效或请求校验失败。
2. **查询天数范围限制**：底层服务接口获取的是墨迹天气未来 15 天预报（`forecast15days`）。因此，传入的起止日期需落在当前时间起的 15 天时间窗口之内；超出 15 天的未来日期将无法获取到预报数据，过滤后将返回空数组。
3. **行政区划匹配机制**：
   - 插件内置包含全国各省、市、区、县级单元的离线匹配库，会自动滤除“特别行政区/自治州/自治区/地区/盟/市辖区/自治县/旗/州/区/县/市/省”等行政后缀进行双向模糊匹配。
   - 若传入的区域名称在数据库中不存在，工具将抛出 `Can not find city` 异常。建议在提示词中约束上游大模型优先输出标准地级市与区县名称。
4. **服务密钥与配额**：请确保填入的 `apiKey` 有效并在对应平台拥有充足的调用点数或额度。如果密钥无效、过期或欠费，接口请求将无法正常返回气象数据。
