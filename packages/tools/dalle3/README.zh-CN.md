# DALL·E 3 绘图工具 (Dalle3 Drawing)

FastGPT 官方 DALL·E 3 图像生成插件。调用 OpenAI DALL·E 3 大模型接口，支持高精度、极具创意的文本到图像（Text-to-Image）生成，并深度集成 FastGPT 宿主文件存储能力，提供图像持久化转存直链，告别第三方临时链接过期烦恼。

---

## 插件简介与典型应用场景

DALL·E 3 是目前业界顶尖的文本生成图像模型之一，具备对复杂语义的深度理解能力，能够忠实还原细节丰富、风格多样的画面设定。

### 典型应用场景
- **文章与自媒体配图生成**：根据文章标题、正文摘要或主题思想，自动生成契合上下文意境的高清插画、自媒体封面或段落配图。
- **视觉设计与创意概念草图**：快速将产品创意构思、科幻场景设定、游戏原画构想转化为高完成度的概念草图，为设计师提供直观灵感。
- **头像、壁纸与海报设计**：定制生成赛博朋克、水墨国风、二次元、写实摄影等多样风格的个性化头像、艺术壁纸与活动宣传海报。
- **图文互动与多模态创作**：在 FastGPT 智能体工作流中实现“故事创作 + 实时插图生成”，打造儿童互动绘本、图文小说、多模态报告等一体化体验。

## 密钥与服务端点配置

在 FastGPT 插件管理中添加或配置该工具时，需填写以下参数：

| 配置项 | 字段名 | 类型 | 是否必填 | 敏感加密 (`isSecret`) | 说明与示例 |
| :--- | :--- | :--- | :---: | :---: | :--- |
| **Dalle3 接口基础地址** | `url` | 字符串 | **是** | 否 | OpenAI API 或兼容网关的基础地址（Base URL）。<br>• 官方接口：`https://api.openai.com`<br>• 中转或聚合平台（如 OneAPI / NewAPI）：例如 `https://api.your-proxy.com`<br>*(注意：末尾无需添加 `/v1/images/generations`，插件会自动拼接标准路径)* |
| **接口凭证（无需 Bearer）** | `authorization` | 字符串 | **是** | 是 | API 访问凭证（API Key）。<br>• 示例：`sk-proj-xxxxxxxxxxxx`<br>• **特别注意**：直接输入密钥字符串即可，**切勿手动添加 `Bearer ` 前缀**，插件底层会自动补齐。 |

## 输出结果与持久化机制

### 输出参数说明

| 参数名 | 对应字段 | 类型 | 说明与示例 |
| :--- | :--- | :--- | :--- |
| **图片访问链接** | `link` | 字符串 | 生成图片的持久化可访问直链（URL）。例如：`https://your-fastgpt-domain/api/system/img/xxxx.png` 或云存储 CDN 地址。<br>*(向后兼容提示：历史工作流中的旧字段 `图片访问链接` 依然受支持)* |
| **错误信息** | `system_error` | 字符串 | 当模型生成异常或接口调用失败时返回的错误详情（如鉴权失败、敏感词拦截、超时等）。若执行成功则为空。 |

### 本地 / 云端持久化转存机制
- **解决临时链接过期问题**：OpenAI 官方 DALL·E 3 生成的原始图片 URL 托管于 Azure 临时存储中，通常在 **1 ~ 2 小时后便会过期失效**。
- **自动持久化上传**：本插件声明了 `file-upload:allow` 权限。图片生成成功后，插件会在底层立即下载图像二进制流，并通过 FastGPT 宿主环境的 `ctx.invoke.uploadFile` 能力自动转存至 FastGPT 本地文件系统或配置的对象存储（如 MinIO、AWS S3、阿里云 OSS 等），输出长期有效的永久访问直链。
- **降级兼容**：在无宿主上传能力的离线或开发测试环境中，插件会自动将图片转换为 Base64 Data URL 格式返回，保证可用性。

## 典型工作流编排与 Prompt 技巧

### 1. 典型工作流编排示例
在 FastGPT 中构建“创意绘图智能体”推荐采用以下节点编排链条：

```
[用户输入] 
   └──> [大模型节点 (LLM: 提示词扩展润色)] 
           └──> [Dalle3 绘图工具节点 (dalle3)] 
                   └──> [文本输出 / 最终回复节点]
```

1. **用户输入**：用户提出简短想法，例如：“画一只赛博朋克风的机械猫咪”。
2. **大模型节点（Prompt 扩展优化师）**：接收用户的简短输入，利用 System Prompt 扩展为专业、画面感丰富、具象化的 DALL·E 3 英文提示词。
3. **Dalle3 绘图节点**：输入参数 `prompt` 绑定大模型节点的输出结果，调用接口生成并上传图片。
4. **最终回复节点**：使用 Markdown 图片语法将结果优雅呈现给用户：
   ```markdown
   这是为您生成的画面：
   ![AI生成图片]({{link}})
   ```

### 2. Prompt 提示词优化师 System Prompt 示例
在大模型节点中填入以下系统提示词，可显著提升 DALL·E 3 的画面成片品质：

```markdown
你是一位顶尖的 AI 艺术提示词工程师。你的任务是将用户提供的简短想法转换为高度详细、画面表现力出色的 DALL·E 3 英文提示词。

请遵循以下优化原则：
1. 主题与细节：明确主体物的外观特征、姿态、衣着与表情。
2. 视角与构图：指定画面构图（如 Wide Angle、Close-up、Cinematic shot、Rule of thirds）。
3. 光影与色彩：指定光照与色调（如 Volumetric lighting、Golden hour、Neon glow、Moody palette）。
4. 艺术媒介与风格：指定艺术风格或渲染引擎（如 Digital art、Unreal Engine 5 render、Oil painting、Photorealistic 8k）。
5. 负面提示转化：DALL·E 3 不支持 Negative Prompt，请使用正向语言描述画面应包含的内容，避免使用“不要/没有”等否定句。
6. 直接输出最终生成的英文提示词，不要附带多余的解释。
```

## 错误排查与常见问题 (FAQ)

### 1. 401 Unauthorized / Invalid API Key
- **现象**：`system_error` 返回 401 鉴权失败或无效的 API Key。
- **排查步骤**：
  1. 检查配置项 `authorization` 是否填写了正确的 API Key。
  2. 确认没有手动添加 `Bearer ` 前缀（例如填成了 `Bearer sk-xxxx`，系统会自动拼接，重复会导致鉴权失败）。
  3. 确认 Key 的额度是否有效、未过期或已被撤回。

### 2. 400 Bad Request / Safety System / 内容安全策略拦截
- **现象**：提示词被 OpenAI 的内容安全审查机制拦截（`safety system` / `content policy violation`）。
- **原因**：提示词中可能包含暴力、血腥、成人限制、政治敏感、侵犯知名公众人物肖像或知名版权 IP 的敏感词汇。
- **解决方案**：调整并优化提示词，避免使用真实知名人物全名、涉及版权争议的专有名词或敏感词，采用中性、隐喻或泛指风格进行描述。

### 3. 连接超时 / Network Timeout / 504 Gateway Timeout
- **现象**：请求耗时过长后报错超时。
- **原因**：DALL·E 3 生成高分辨率（1024x1024）图像通常需要 10 ~ 25 秒。如果网络代理、API 中转网关或反向代理（如 Nginx）的超时时间配置过短（如 15 秒），将导致连接中断。
- **解决方案**：调高反向代理网关的超时阈值（建议设置为 60 秒以上），并确保 FastGPT 部署服务器至 OpenAI 或中转节点的网络畅通。

### 4. 429 Too Many Requests / Insufficient Quota
- **现象**：请求频率超限或账户余额不足。
- **解决方案**：检查 OpenAI 账户账单充值状态，或在中转渠道中确认当前 Token/额度是否充足。如遇到并发限制，可在工作流中增加等待重试机制。
