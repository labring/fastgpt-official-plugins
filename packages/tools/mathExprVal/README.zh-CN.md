# 数学公式执行 (Math Expression Evaluation)

数学公式执行插件是 FastGPT 官方提供的精确数学表达式求值工具。通过集成轻量安全的 `expr-eval` 解析引擎，本插件可对复杂的算术运算、代数表达式、三角函数、指数与对数等进行快速确定性求解，有效消除大语言模型（LLM）在面对复杂数字运算时的“幻觉”与计算误差。

## 应用场景

- **消除大模型计算幻觉**：大模型擅长语义理解但欠缺确定性运算能力，在面对多位数加减乘除、带括号的多层嵌套运算时容易出错，通过本工具可实现 100% 精确的代数求解。
- **财务与商业指标核算**：用于复合利率折算、毛利率计算、折扣与税费拆解等高准确率要求的财务公式自动化求值。
- **工程与科学公式求值**：支持三角函数（如 `sin`, `cos`）、开方（`sqrt`）、乘方（`^` 或 `**`）、对数（`log`, `ln`）等常见科学计算。
- **动态工作流参数统计**：在流程编排中动态计算分页偏移量、阈值比例及统计得分等衍生数值指标。

---

## 核心特性与安全机制

- **免 API 密钥配置**：开箱即用，无需任何第三方服务密钥或外部网络连接。
- **专用安全沙箱**：基于 `expr-eval` 专用数学表达式 AST 语法解析引擎执行，严格区别于 JavaScript 原生 `eval()`，彻底杜绝任意代码执行（RCE）与系统环境逃逸风险。
- **操作符智能兼容**：自动兼容将 Python/JS 常见的乘方符号 `**` 转换为标准数学乘方符 `^`。

---

## 输入参数说明

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `expr` | 字符串 | **是** | - | 待计算的数学表达式。兼容旧版中文字段名 `数学表达式`。例如：`(12.5 + 3.75) * 4 ^ 2`。 |

> **提示**：支持标准数字、四则运算 `+ - * /`、求余 `%`、乘方 `^` 或 `**`、圆括号优先级 `( )`，以及内置常量与函数（如 `PI`, `E`, `sin(x)`, `cos(x)`, `sqrt(x)`, `abs(x)`, `round(x)` 等）。

---

## 输出结果说明

| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `result` | 数值或字符串 (`number \| string`) | 表达式计算成功时返回数值类型结果；表达式语法有误时返回带有错误原因的提示字符串。 |

### 输出示例

**计算成功**：
```json
{
  "result": 260
}
```

**语法错误**：
```json
{
  "result": "12 + * 3 is not a valid math expression. Error: ..."
}
```

### 提示词引导建议 (System Prompt)

在引导 LLM 调用本工具时，建议在提示词中约束其输出干净纯粹的数学表达式：

```text
遇到涉及数学计算或数值公式的问题时，请先将用户的自然语言问题转化为标准的数学表达式传递给 mathExprVal 工具（例如将 "1500 的 85 折再减 50" 转化为 "1500 * 0.85 - 50"），不要在表达式中混入文字、中文字符或等号。
```
