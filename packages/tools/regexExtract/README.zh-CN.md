# 正则表达式文本提取 (regexExtract)

使用 JavaScript 正则表达式从源文本中精准提取匹配内容。

## 输入参数说明

- `text`：需要进行提取的源文本字符串。
- `pattern`：JavaScript 正则表达式模式（无需包裹首尾斜杠 `/`）。
- `flags`：可选的正则匹配修饰符。支持 `gimsuyd`；默认会自动附加全局匹配 `g`。
- `group`：可选的捕获组选择器。可使用捕获组序号（如 `1`）或具名捕获组名称（如 `email`）。

## 输出结果说明

- `matches`：所有提取出的匹配项数组。
- `firstMatch`：首个提取出的匹配值（若无匹配则为空）。
- `count`：提取出的匹配项总数。
- `error`：当正则表达式语法无效时返回的错误信息。
