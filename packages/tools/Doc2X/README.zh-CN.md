# Doc2X 文档解析服务 (Doc2X Service)

Doc2X 是一款专注于将复杂排版、多栏布局、表格以及学术数学公式的高难度文档深度解析为结构化 Markdown 的专业文档解析服务。

本插件为 FastGPT 提供了开箱即用的 Doc2X 文档识别与转换能力。通过调用 Doc2X 深度学习解析管线，能够高精度识别学术论文、教材试卷、研报白皮书中的行内公式与块级 LaTeX 公式，自动还原双栏/多栏混排布局，并将复杂表格转化为标准 Markdown 表格，为 FastGPT 智能体工作流、大模型阅读理解以及 RAG 知识库检索提供高保真的文档预处理支撑。

---

## 典型应用场景

- **学术论文与科研文献解析**：精准提取计算机、数学、物理等领域论文中的复杂矩阵、多行推导公式、定理证明与图表引用，保留公式语义。
- **复杂排版与多栏文档数字化**：处理学术期刊、行业研报、咨询报告等双栏或多栏混排 PDF，自动识别阅读流与层级标题，避免传统 OCR 的错位与乱序。
- **教材、试卷与题库数字化录入**：解析包含理科公式、题干图解、选择题选项的试卷与教辅资料，转换为带 LaTeX 语法的标准化 Markdown 文本。
- **知识库问答增强 (RAG) 前置处理**：配合 FastGPT 上游文件上传节点或知识库入库流程，将用户上传的原始 PDF 解析为富文本 Markdown，极大提升文档切片质量与向量召回准确率。

## 密钥配置说明

使用本插件需要配置 Doc2X 开放平台的 API 密钥（`apikey`）。

### 获取渠道

1. 访问 [Doc2X 开发者平台](https://doc2x.noedgeai.com)（或官网）注册并登录账号。
2. 进入控制台的「API Key / 密钥管理」页面创建新的 API 密钥。
3. 复制生成的密钥字符串（请妥善保管）。
4. 确认账户中具备可用的页数或点数额度（新用户享有初始赠送额度，商业调用需根据需求充值）。

### 配置方式

在 FastGPT 的工具密钥管理或节点配置中填写以下字段：

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `apikey` | 字符串 (`string`) | 是 | Doc2X 开发者平台 API 密钥。请求时将作为 Bearer Token 进行身份鉴权与点数扣减。 |

## 子工具列表

本工具集目前包含以下子工具：

- **`PDF2text`（PDF 识别 / PDF Recognition）**：将输入的 PDF 文件通过 Doc2X 异步解析管线转换为结构化 Markdown 文本，并完整提取与规范化 LaTeX 公式。

---

## 子工具：PDF2text (PDF 识别)

### 输入参数

| 参数名 | 字段类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `files` | 字符串数组 (`Array<string>`) | 是 | 无 | **PDF 文件直链 URL 列表**。支持传入单个或多个公网可访问的 PDF 文件直接下载地址，通常通过连接 FastGPT 文件上传节点或引用上游流程中的文件输出变量传入。 |

### 输出结果

| 字段名 | 字段类型 | 说明 |
| --- | --- | --- |
| `result` | 字符串 (`string`) | **转换后的 Markdown 正文**。包含标准 LaTeX 数学公式（行内 `$ ... $` 与独立块级 `$$ ... $$`）、格式化 Markdown 表格与图片引用。当传入多个文件时，各文件的解析结果之间使用水平分隔线 `\n------\n` 分隔。 |
| `success` | 布尔值 (`boolean`) | **处理是否全部成功**。当且仅当传入的所有 PDF 文件均下载并成功解析时返回 `true`；若存在任何一个文件处理失败，则返回 `false`。 |
| `error` | 字符串 (`string`) | **错误信息**（可选）。当解析失败、超时、下载异常或鉴权失败时返回具体错误原因。多文件解析产生多个错误时同样使用 `\n------\n` 分隔。 |

### 输出示例

```json
{
  "result": "# 深度学习中的注意力机制研究\n\n## 1. 引言\n\n自注意力（Self-Attention）机制的计算公式如下所示：\n\n$$\\text{Attention}(Q, K, V) = \\text{softmax}\\left(\\frac{QK^T}{\\sqrt{d_k}}\\right)V$$\n\n其中 $Q, K, V$ 分别代表查询（Query）、键（Key）和值（Value）矩阵。\n\n| 参数 | 维度 | 含义 |\n| --- | --- | --- |\n| $d_k$ | 64 | 键向量维度 |\n| $d_v$ | 64 | 值向量维度 |",
  "success": true
}
```

## 典型工作流编排示例

### 场景一：配合文件上传节点实现论文研读对话

1. 在 FastGPT 应用工作流中添加「用户文件上传」或「对话输入」前置节点。
2. 连接「Doc2X Service -> PDF 识别 (`PDF2text`)」节点，将上游文件输出变量（例如 `{{fileUrls}}`）绑定到 `files` 输入参数。
3. 将 `PDF2text` 节点的输出变量 `result` 连接至「AI 对话 / LLM 处理」节点的系统提示词或上下文输入。
4. 在模型提示词中引导 LLM 对论文的核心创新点、数学推导公式及实验结论进行提炼总结。

### 场景二：高质量学术知识库数据预处理

1. 批量获取待入库的专业学术论文或教材 PDF 下载链接。
2. 调用 `PDF2text` 工具将 PDF 转化为结构化 Markdown。
3. 将清洗格式化后的 Markdown 文本导入 FastGPT 知识库进行分块切片与向量化入库，完整保留数学公式结构，显著提升 RAG 的专业召回能力。

## 注意事项

1. **文件格式要求**：当前工具仅支持 PDF 格式文件。节点在下载文件时会严格校验 HTTP 响应头的 `Content-Type`（需以 `application/pdf` 开头），非 PDF 格式文件将被自动忽略跳过。
2. **下载链接与网络可达性**：传入的 `files` 必须为外部网络可直接免登录下载的有效 URL。单文件下载请求超时时间为 20 秒，请确保文件托管存储网络稳定。
3. **异步解析机制与耗时**：Doc2X 采用服务端异步排队解析管线。工具内部会自动轮询解析状态（单文件上限重试 120 次，单次间隔 5 秒，最长超时约 10 分钟）。复杂、长篇幅或高分辨率图表的 PDF 解析耗时可能在数十秒到数分钟不等；多文件将按输入列表顺序串行处理，总体耗时将线性累加。
4. **账户余额与配额**：调用 Doc2X API 会扣减相应账户的点数或页数配额。请确保在 [Doc2X 开发者平台](https://doc2x.noedgeai.com) 保持足够的可用额度，否则会返回欠费或权限错误。
5. **公式与排版优化**：插件内置针对 Markdown 与 LaTeX 的深度后处理：
   - 自动将 `\(` / `\)` 统一规范化为行内公式 `$ ... $`。
   - 自动将 `\[` / `\]` 统一规范化为块级公式 `$$ ... $$`。
   - 自动将 HTML 结构表格清洗转换为主流 Markdown 表格语法。
   - 过滤无关冗余标记（如空注释块等），确保大模型可无障碍理解。
